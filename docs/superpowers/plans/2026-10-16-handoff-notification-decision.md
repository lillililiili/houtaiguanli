# 无人机事件后续通知简版实施计划

已确认设计：沿用“移送与处罚”页面，现场处置结束自动进入待办，人工一次点击通知上级接口，或填写原因选择不通知。送达和签收仍依据实际回执；不承接上级后续处罚流程。

## 边界

- 已确认事件 + 明确飞离依据、有效不反制决定或实际停机完成事实可入待办；位置未知不代表飞离。
- 同事件幂等，只生成内部待办，不自动发送；缺少或冲突的接口配置不能让待办消失。
- 权限、数据范围、版本校验、审计、历史材料和真实/模拟隔离保持。历史记录不批量回填。
- 不新增接手、审批、办结环节；保持页面布局和历史结果只读。保留其他风险通知行为。
- 验收使用模拟来源，开发种子关闭；不修改凭据、不删除数据、不触碰云端。
