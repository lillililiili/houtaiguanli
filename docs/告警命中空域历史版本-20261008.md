# 告警命中空域历史版本（2026-10-08）

## 页面与口径

告警事件 → 选择告警 → 关联目标定位与轨迹。地图显示该告警首次发生及实际升级记录关联研判中命中的具体空域版本。点击范围可查看空域编号、历史版本、类型、限高、生效时段和对应命中记录；小地图弹窗可以滚动，内容完整可读。

范围、类型、限高和时段取保存的版本；名称、编号和管理单位为目录资料，不声称是冻结名称。目标和航迹仍沿用已有观测展示，不声称是告警瞬间的全场景快照。历史范围不作为当前生效空域或当前异常闪烁。

缺少历史依据显示“未保存告警时空域依据”；部分依据缺失或不可见单独提示；无确认命中、无权限及读取失败分别显示。不补写历史、不以今天的版本或目标最新研判替代。

## 后端契约

新增只读 `GET /api/v1/alarms/{alarmId}/airspace-hits`。要求告警、空域、研判及目标读取权限，叠加原有组织、区域、来源和目标关联校验。

从告警 detail.evaluation_id 与 alarm_escalation.evaluation_id 读取固定研判，仅收录 ACTIVE 研判中 C02-1/C02-2/C02-8 的 FAIL 命中，使用 facts.airspace_version_id 查询固定版本并核对空域 ID。不重新执行规则。返回 status=AVAILABLE/NO_HIT/UNKNOWN/PARTIAL 及 items；item 包含 occurrence、evaluatedAt、observedAt、ruleCode、reasonCode、airspace（含 version）。首次 occurrence=0，其余为实际升级序号。

## 代码清单

- 前端 `src/services/alarmApi.js`：getAlarmAirspaceHits 读取契约。
- 前端 `src/pages/AlarmsPage.vue`：loadMapAirspaces 加载、合并同一版本的命中说明；focusMap 纳入历史范围及状态提示；选择切换防止旧响应串入。
- 前端 `public/assets/js/map.js`：历史说明转义展示；scrollableTip 限定告警小地图弹窗滚动，不吞滚轮缩放。
- 后端 `AlarmAirspaceController`：新增读取入口；`AlarmAirspaceReadService.read`：串联固定证据、权限、来源及状态。
- 后端 `AlarmReadRepository.airspaceEvaluationReferences`：只取同一告警与范围元组下的实际升级记录。
- 后端 `AirspaceReadService.versionContext` 与 `AirspaceDtos.VersionContextDto`：提供有权限的固定版本几何与目录上下文。
- 后台管理端无该新增接口消费者；原公共接口保持不变，无数据库迁移。
