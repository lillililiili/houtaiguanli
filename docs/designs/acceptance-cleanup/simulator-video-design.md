## 状态与操作

1. 启动 MQTT 模拟前，在连接设置显式启用测试视频。
2. 平台真实下发 BeginTracking 后，模拟器按绑定和当前开放任务决定是否执行；没有对应任务不能通过 UI 强行造回执。
3. 同一设备只能保持一个任务；重复下发只重复必要回执，不新建编码进程。
4. 跟踪已执行而 FFmpeg 不可用时，同时展示“跟踪中 / 视频失败”，不把失败改成可播放。保留当前任务登记，每15秒先确认同一OPEN任务再重试编码；任务关闭或模拟暂停停止则不会恢复。
5. 暂停、停止、离线或任务结束释放编码和流登记；恢复发送不继续旧任务，界面保留停止事实。
