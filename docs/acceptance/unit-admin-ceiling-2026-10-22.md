## 本次规则

- 有效单位管理员直接继承平台为本单位明确开放的前台模块、菜单、动作及后台管理功能，不再与个人角色取交集。任命时无需另建或分配管理员角色，也不自动复制角色。
- 普通人员仍按本单位角色与单位上限的交集授权。数据范围为精确本单位，不包含下级单位。
- 原人员角色绑定保留。撤任或替换管理员时，离任人员必须保留启用的本单位角色，或在同次保存中明确分配。
- 直接反制只认单位显式 OP；后台运维权限不替代前台业务动作。平台接口、申请不能自审、设备与证据校验保持。
- 发送前查询实际有效权限；撤权影响未发送操作，已启动设备的停止与回执继续完成。

## 实现与界面

## 人工复验步骤

1. 平台管理员打开“用户管理 → 目标单位的菜单 → 单位授权”。
2. 在“管理员”选择本单位账号，设置“前台权限”和“后台功能”。管理员本人无需创建新角色；有普通人员时，为其他人员分配本单位角色。
3. 点击“保存并立即生效”。让该管理员重新登录前台和后台。
4. 后台“本单位角色 → 我的权限”应与该单位已开放功能一致；只能看到本单位数据，不含子单位。
5. 平台关闭一项权限并保存，确认旧会话失效，重新登录后对应功能不可用；恢复单位权限后管理员重新获得该功能，普通人员仍受自身角色约束。
6. 如需撤任或替换，给离任管理员选择启用的本单位人员角色，再保存；确认离任账号不再拥有单位管理身份。
