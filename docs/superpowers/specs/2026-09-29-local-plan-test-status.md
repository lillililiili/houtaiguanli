# 本地计划模拟状态输入

用户已授权补齐缺失测试条件并持续测试。本次只扩展已有 local+qa/test 受控模拟计划输入，不新增正式审批、起降判断或修改旧计划的接口。

现有 POST /api/v1/local-interface-simulator/plans 固定PENDING，阻塞执行中、完成和取消计划的页面验证。选择追加可选status_code，省略仍为PENDING；允许PENDING/EXECUTING/COMPLETED/CANCELLED，保持mock/replay来源与原接口权限/对象范围/消息幂等。拒绝未知状态与时间矛盾：执行中必须处于计划窗口，已完成必须已过结束时间。状态作为显式模拟来源输入，不代表实际飞机完成，也不填充轨迹或处罚结果。

替代方案是启用全库时间推进或直接改库，都会影响历史，不采用。既有前端不传新字段，行为兼容。先通过API补齐测试样本，模拟器状态表单不属于此次必要范围。

验证默认兼容、四状态、无效输入、消息冲突、来源隔离、无权限、业务读取；SQL变更在隔离PostgreSQL验证。包构建后仅在确认当前运行配置后更新后端，保留其他光电代码。
