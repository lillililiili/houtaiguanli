# 无人机平台后台管理前端

Vue 3、Vite、Pinia 与 Element Plus 实现的若依风格管理端，默认运行在 `5175`。它与业务前台共用 `../server` 的 `/api/v1` 接口，但会话仅保存在当前标签页的 `sessionStorage` 中。

```powershell
npm install
npm run dev
```

质量检查：

```powershell
npm run lint
npm test
npm run build
```

开发环境通过 `/dev-api` 代理到本仓库新后端 `http://127.0.0.1:8081/api`；可用 `ADMIN_API_PROXY_TARGET` 显式覆盖。生产静态站点通过 `/api` 反向代理到统一后端。切换后端后，旧后端的会话不通用，需要重新登录。


## 单位与通知配置（2026-09-16）

单位资料在用户管理维护，通知对象配置保留独立入口；菜单与读取权限共同决定可访问入口，维护另需对应授权权限。

- **单位资料并入用户管理** `/system/users`：左侧单位树继续筛选用户；在当前单位旁或单位菜单点击“查看单位”，弹窗查看基本信息、联系人及关联信息。点击“编辑单位”在同一弹窗维护名称、上级单位、类型、统一标识、地址及备注；新增下级单位自动带入上级。来源映射、计划关联收在关联信息。独立单位档案菜单取消，旧 `/system/organizations` 地址转到用户管理。
- 通知对象配置页已撤回，后台不再提供新增或修改通知渠道的入口。飞手短信、飞手电话、风险通知上级和处罚送达仍读取已经保存的配置，不从本页维护。
- 设备管理原有运维待办详情，在后端返回相关字段时显示最近通知结果与接收快照；结果未知明确显示未知，后续失败不覆盖此前送达事实。点击“查看通知记录”可展开每次通知的冻结接收资料、配置版本、提交/送达/确认时间与回执内容，模拟通知和历史资料转存单独标识。后台只查看通知记录与记录运维处理结果，再次通知仍从业务前台发起；已反馈待办不代表设备已恢复。

以上为代码入口说明，不能据此认定迁移已在业务数据库应用或正式通道已接通。
# 规则管理与原处置预案入口（2026-09-17）

系统管理“规则管理”（`/system/response-plans`）只服务前台告警到处罚的自动执行，不控制人工按钮。本地每类预置两条规则：核实为高置信度且观测仍有效，满足后系统自动核实属实；反制为观测仍有效且达到高风险；通知处罚为事件已关联当前目标且通知依据仍有效。没有已启用规则时，该步骤不会自动执行。页面顶部已移除“运行记录”“变更记录”入口，后台判定记录与配置审计仍保留。全局配置及运行记录要求 ALL 数据范围及 `responsePlans.read/auth` 权限。详见[规则判定运行说明](../docs/规则判定引擎接入-2026-09-17.md)。

原处置预案兼容地址 `/system/response-plans/legacy` 保留，规则管理顶部不再展示关联入口：保存草稿、发布或停用具体版本、关联同组织与区域内空域，查看关联历史。权限使用 `responsePlans.read` / `responsePlans.auth`，普通角色按现有角色管理分配。业务前台只读查询；发布、关联不发送通知或下发设备指令。[接口说明](../docs/处置预案接口-2026-09-17.md)。

单位资料沿用 `organizations.read` / `organizations.auth`，原单位菜单权限兼容进入用户管理，仅单位权限不会读取用户账号列表。仅有 `users.auth` 的账号仍可维护原单位名称和层级；扩展资料、联系人及关联信息按单位资料权限控制。联系人无需先建账号，历史通知快照、既有单位 ID 与计划关联保持原样。


### 临时公网预览的登录代理

通过已授权的公网隧道访问管理端时，启动 Vite 前设置 `ADMIN_PUBLIC_ORIGIN` 为该入口的完整 HTTPS origin（不带尾斜杠）。代理仅将这个精确来源规范化为本地管理端 origin，避免同源登录被后端 CORS 拒绝；其他来源仍由后端原有 CORS 校验。此配置不替代登录和权限校验，不应填入不受信任的站点。

### 接口配置与天气传感器（2026-09-20）

运维管理新增“接口配置”（`/operations/interfaces`，原 `interfaces.read/op`），提供飞行计划输入与天气预报配置草稿的服务端保存。已有非管理员角色如未显示入口，需按现有角色菜单配置检查“接口配置”，本轮未授予新动作权限。设备管理新增天气传感器登记/编辑和类型筛选；登记后停用、气象观测为空，不发起设备连接。当前上游计划系统、预报服务商和传感器协议待提供，真实接收/采集尚未实现。接口及边界见 [对接说明](../docs/飞行计划天气接口配置.md)。

2026-09-20 后续：天气接口支持用户授权的本地模拟模式。运维管理 → 接口配置 → 天气预报，选择“模拟接口”，填写名称和区域后保存，可返回一批 24 小时模拟预报；状态显示“模拟已启用”，到期重新保存生成新批次。真实模式仍待正式接口资料，不自动回退模拟。计划输入、传感器仍未实际接通。
