# 验收清理页面设计 V1

日期：2026-09-28。此目录是独立评审稿，不是正式业务代码。

## 打开与使用

打开 index.html，或者使用本地预览 http://127.0.0.1:8791/ 。没有外部依赖，不需要登录。

- 顶部切换 9 个设计页面。
- “现状结构 / 修改后 / 前后对照”切换同一页面的两版；对照模式纵向排列，避免缩得太小。
- 红色为删除、蓝色为调整、绿色为保留；点编号或说明卡会定位对应区域。
- “显示改动标注”可关闭标注，查看干净页面。
- “放大页面”以 1280 CSS 像素原尺寸查看；窄窗口可横向滚动。
- “查看状态”切换空态、错误、等待回执、断流等设计状态。
- 设计中的保存、发指令、导出等业务按钮只提示设计预览，不产生业务操作。

## 本版范围

| 页面 | 基于现有区域 | 本次设计内容 |
| --- | --- | --- |

## 已确认边界

1. 短信流程不改；录音电话按同一通知模块暂保持原样。
2. 独立数据模拟器保留用于联调；清理的是业务系统自身生成的数据、画面和假成功路径。
3. 视频必须来自外部流。当前视频组件实际为 Canvas 模拟画面，当前查到的数据模拟器未实现视频推流；本稿不代表推流接入已完成。
4. 所有编号、设备、时间和指标为明确标识的设计样例。成功状态仅展示样式，不代表设备、渠道或规则已经通过验收。
5. 不删除历史、不改 Flyway、不调整数据库；原模拟记录保留来源，不能仅去掉标识。
6. 正式统计过滤、模拟入口后端限制、可信回执、规则参数确认都需要后续实现与验证，设计图本身不能完成这些约束。
7. 正式规则确认不是给演示规则直接改标签；模拟器联调通过不等于实际设备验收通过。
