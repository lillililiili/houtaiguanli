# 实时推送接口（2026-10-04）

用户要求融合感知以外的页面也实时接收数据，并选定“后端推送”方案。本接口只推送“哪类数据变了”，不推送业务数据；页面收到信号后经原有接口按当前筛选、分页和权限重读。

## 接口

`GET /api/v1/realtime/events`，`Accept: text/event-stream`，`Authorization: Bearer <session_id>`。未登录返回 401（`{ok:false}` 包装），连接数超过 `app.realtime.max-connections`（默认 200）返回 503 `REALTIME_BUSY`。

| 事件 | data | 说明 |
| --- | --- | --- |
| `ready` | `{"listening":true,"at":<epoch ms>}` | 连接建立；`listening=false` 表示数据库监听未启用（非 PostgreSQL 或 `app.realtime.enabled=false`），只有心跳 |
| `change` | `{"topics":["alarm","target"],"at":<epoch ms>}` | 有变化的数据类别；`"*"` 表示监听重连后需全部重读 |
| 注释 `:ping` | — | 每 `app.realtime.heartbeat-millis`（默认 20 秒）一次，保持代理连接 |

连接在 `app.realtime.stream-timeout-millis`（默认 10 分钟）后结束，前端重连并重新鉴权。响应带 `X-Accel-Buffering: no`，Nginx 不缓冲。

## 信号来源

迁移 `V202610040001__realtime_data_change_notify.sql`（`db/postgresql`）为业务表建语句级 INSERT/UPDATE/DELETE 触发器，借助转换表只在确有行变化时 `pg_notify('app_data_change', <topic>)`。信号随事务提交送达，回滚不发；应用、模拟器受控 seed 和手工 SQL 的写入都会产生信号。`DataChangeListener` 用独立连接 `LISTEN`，按 `app.realtime.flush-millis`（默认 300 ms）合并后经 `RealtimeHub` 分发。

| topic | 表 |
| --- | --- |
| `alarm` | alarm、alarm_merge_group/member、uav_event、uav_event_verification/advisory/voice_advisory |
| `target` | target、target_latest_state、target_source_link、target_track_status、track_point、ops_target_latest_state、ops_track_point、sensing_target |
| `legality` | legality_review、legality_review_history、assessment_result |
| `risk` | flight_risk、flight_risk_verification、space_risk_fact、weather_risk_fact、risk_clearance_evidence |
| `plan` | flight_plan、flight_plan_verification、flight_plan_feedback、route、route_version |
| `airspace` | airspace、airspace_version、airspace_delivery |
| `device` | device、device_state、device_incident、device_event_log、ops_device、ops_device_state、ops_device_maintenance_task、commission_task、commission_task_event |
| `disposal` | disposal_authorization(_event)、disposal_emergency_stop、device_command、eo_tracking_task、eo_target_control |
| `evidence` | evidence_file、evidence_link |
| `punishment` | punishment_case(_event)、handoff、handoff_delivery |

`uav_auto_sms_task`、`uav_auto_voice_task` 是后台任务的租约与轮询记账，每秒都有更新且页面不显示，不纳入信号。

## 前端接入

业务前台 `src/services/realtime.js` + `src/hooks/useRealtimeRefresh.js`，后台管理端 `src/services/realtime.js`。EventSource 不能带 Bearer 头，改用 fetch 读流；断线指数退避重连，推送不可用时每 15 秒通知一次重读。页面重读时保留筛选、分页、选中项和滚动位置，选中行本身变化时才重读详情；同一页两次重读至少间隔 1–2 秒（统计页 10 秒、大屏 5 秒），页面隐藏时不读。原有定时刷新保留为兜底。
