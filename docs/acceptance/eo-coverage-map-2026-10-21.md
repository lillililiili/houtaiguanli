# 光电视频小地图覆盖范围修复

本轮仅修改业务前台光电视频小地图。用户指出放大后没有无人机、视野仍是全市；实测主图有2架当前无人机，而小图沿用了主图相机位置，未按设备配置聚焦。此前实拍双流、视频识别框、核实反制服务保持。

## 行为

- 放大后仅装载当前光电设备及配置圆形/扇形范围内的当前无人机；自动按射程、方位及张角定位，范围外底图压暗，增加范围内目标数量。
- 复用台账覆盖判断，不补默认射程；范围或位置未知显示原因。离线设备保留配置参照范围，但明确能力不可用，不能把范围内其他来源目标当作本机已探测。
- 小图目标和范围不受主图图层隐藏影响；点选与框选沿用同一告警选择清单。缩小后还原主图视野和图层，选择保留；全程只使用一个地图宿主和业务叠加画布。
- 清单的定位只聚焦当前光电范围；范围外目标提示到主图查看，范围未知直接显示原因。查看、选择及缩放不下发设备指令。
- 配置覆盖范围与当前镜头画面分别呈现；地图上可有两架无人机，视频仅展示实际关联的那一架。
