# 流程9光电视频与提前预警的观测连续性修复

## 故障依据

2026-10-22 用户报告流程9“6分钟继续入区”直接出现实测入区告警。目标 `20261022-011` 的运行库记录中没有预测风险周期；接近禁飞区前的有效预测仅短暂出现，随后出现观测过期、轨迹不连续及观测冲突。融合实测在北京时间 17:45:05.963 至 17:45:15.199 之间中断约9秒，后续仍有多秒间隔，超过 K03 的连续性与新鲜度门槛。

模拟器此前在位置上报主循环内同步执行光电视频注册、FFmpeg 检查及视频逐帧元数据请求。这些操作耗时会推迟正常的每秒位置上报；主循环还会把等待前采样的位置与等待后的时间组合，且标准观测与 MQTT 时间各自取值，造成速度与双源一致性偏差。

## 修复

- 光电任务、视频处理及结束回执由单独的串行工作线程负责。位置发布不等待视频 HTTP 请求；设备状态使用受锁保护的快照。
- 暂停、恢复、配置变更仍串行生效。即使快速暂停后恢复，也先结束旧任务。停止时等待当前操作及最后停止回执处理完成，再断开 MQTT；不伪造停止成功。
- 完成可能阻塞的会话/重连检查后重新采样航迹时间，同一帧的标准观测与 MQTT 共用一个采样时间，不把旧位置标成新观测。
- 保留原 K03 样本数量、时间跨度、最大间隔、稳定性和三次确认门槛。未修改预测核实、通知、反制、处罚或权限逻辑；未修改已发布规则及历史。
