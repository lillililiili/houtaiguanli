# Report font

Noto Sans SC, regular weight (400), bundled for offline, searchable Chinese PDF reports.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The upstream `NotoSansSC[wght].ttf` was instantiated at weight 400 using fontTools.
The accompanying OFL.txt is the upstream SIL Open Font License. No operating-system
font or runtime network download is required.
