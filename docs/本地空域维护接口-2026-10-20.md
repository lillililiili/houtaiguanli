# 本地空域维护接口

用户最新确认：现有代码增加空域增删改查和三维编辑，本地及上级下发空域均可由平台编辑、删除；暂不改造 UM，保留现有上级空域下发接口。本条替代先前“上级只读”。

## 数据与权限

水平边界使用 WGS84 GeoJSON MultiPolygon（经度在前、纬度在后，闭合环）；垂直范围使用 `min_altitude_m`、`max_altitude_m` 和固定 `altitude_datum=AMSL`。两项高度均必填，上限严格高于下限，负海拔允许；最多两位小数，绝对值不超过 99999999.99 米，避免入库舍入改变体积。不转换旧 AGL 值。多区域、内孔原样保存，几何合法性最终由后端校验。

本地维护需要 `airspace:read`、`airspace:manage` 及完整的归属单位/区域权限；普通角色只恢复动作可配置能力，不自动授权。Bearer 数据库会话、snake_case、`{ok,data,error}` 和字符串 ID 不变。写请求携带 `Idempotency-Key`，修改及删除携带 `expected_version`。

列表与详情增加 `management_source`（LOCAL / UPSTREAM / LEGACY）、`editable`、`deleted_at`。来源依据原接入关系和版本来源记录判定。LOCAL/UPSTREAM 均可在权限范围内维护，来源标识不因平台编辑改成 LOCAL；新增版本记 MANUAL，原下发版本、来源及回执保留。未验证来源的 LEGACY 旧资料只读。

## 接口

| 方法及路径 | 请求 / 返回 |
| --- | --- |
| `GET /api/v1/airspaces/management-context` | 返回 `scopes`，每项有 `owner_org_id, owner_org_name, district_id, district_name` |
| `POST /api/v1/airspaces` | `airspace_no, name, owner_org_id, district_id, kind_code, boundary, min_altitude_m, max_altitude_m, altitude_datum, valid_from, valid_to, change_reason` |
| `PUT /api/v1/airspaces/{id}` | `name, kind_code, boundary, min_altitude_m, max_altitude_m, altitude_datum, valid_from, valid_to, change_reason, expected_version`；编号及归属不变 |
| `DELETE /api/v1/airspaces/{id}` | JSON `expected_version, change_reason`；返回 `airspace_id, version, deleted_at` |

POST/PUT 返回 `airspace_id, airspace_version_id, version_no, version`。时间为 epoch 毫秒；界面按北京时间录入和展示。`valid_to` 可为空，其他字段按上表必填。修改追加新版本，生效时间必须晚于最新版本；不就地改写旧几何和高度。

## 删除及历史

删除记录 `deleted_at`，常规列表退出展示，删除时刻及之后不再参与有效空域、空间命中或未来排期生效。旧版本几何、高度、有效期和历史引用保留；历史时点查询按删除时间截断，版本详情继续可读。删除不向 UM 回写。

上级下发空域经平台编辑后，原下发身份仍以最近一条 UPSERT 原始回执的名称、原归属和来源校验，平台显示名称不会被后续下发覆盖。新下发继续遵守 revision 和生效时间递增规则，不能覆盖已排期的更晚版本。平台删除后，同一对象的新 UPSERT/WITHDRAW 返回 409 `AIRSPACE_DELETED`，不自动恢复；原消息重放仍返回原历史回执。

## 前端

业务前台空域管理增加“新增空域”“三维编辑”“删除空域”。三维编辑器使用同一组经纬度和海拔数据，支持旋转、缩放、拖动边界顶点、拖动上下限及精确数值录入。默认“突出高度”模式仅在水平范围大、投影厚度过薄时放大显示垂直轴，并明确标注倍率和真实海拔；“真实比例”可还原水平与垂直的同一米制比例。显示倍率不改变保存值，拖动按同一倍率反解为实际坐标和海拔，视图不是地形估算。日常地图仍显示平面边界。修复及验收见 [大范围空域高度显示记录](acceptance/airspace-height-visibility-2026-10-21.md)。

无权限、资料缺失、版本冲突、非法几何和网络结果未知均显示原因。非 AMSL 的旧资料允许进入编辑，其海拔字段留空并提示重新填写，不把旧离地高度直接当作海拔。保存成功后重新读取列表和详情，删除前明确确认。验收始终保持开发种子关闭。
