4. 浏览器拒绝全屏时提示错误，不伪装成功。
5. 全屏中分片返回 503，恢复后继续播放。
6. 全屏中分片返回 401，停止画面并退出全屏。

## 第 17 项

`app.flight-device-check.schedule.enabled` 默认 `false`，环境变量 `APP_FLIGHT_DEVICE_CHECK_SCHEDULE_ENABLED`。独立任务每 60 秒扫描有效执行窗口；启用任务不要求页面打开或管理员会话。部署验收仍保持 `app.dev-seed.enabled=false`。

持久化表：

- `flight_device_check_schedule`：范围摘要、计划版本、下次检查时间、最近结果及失败状态。
- `flight_device_check_fault`：计划/设备的故障实例、设备告警引用、恢复状态及任务关联。

使用计划行锁串行化检查，使用设备行锁和原活动任务唯一约束保护建单；建单前在设备锁内重新检查范围与当前异常。每计划独立事务，失败保留重试状态。正常/未知均不会宣称已起飞或未起飞，`takeoff_status=UNKNOWN`。持续故障办结后不重复自动创建；完整正常事实使故障实例结束，之后新故障可重新建单。关闭一部分未关闭告警不算新故障。

读取 `/api/v1/flight-plans/{planId}/verifications` 新增 `scheduled_check`：

- `last_checked_at`、`next_check_at`：epoch 毫秒；发现对应目标后不冒充一次新的设备检查。
- `state`：`PENDING / CHECKED / MATCHED / FAILED`。
- `failure_code`、`verification_id`、`maintenance_task_ids`；`maintenance_tasks` 提供关联设备名称及原运维流程状态，页面只读展示。
- 核验记录新增 `trigger_type=USER / SYSTEM`；SYSTEM 不伪造用户 ID。

页面每 30 秒被动读取保存结果，刷新不触发建单。人工通知报送单位继续走原入口。

## 第 25 项输入契约

`POST /api/v1/local-interface-simulator/flight-execution-facts` 仅在既有模拟环境门禁下开放，要求登录、外部接口操作权限和目标范围。真实来源仅保留内部适配器用例，没有普通用户写入 live 可信事实的入口。

请求采用 snake_case：

| 字段 | 约束 |
| --- | --- |
| `source_id`, `source_mode` | 来源已启用，模式与目标一致；模拟入口仅 mock/replay |
| `message_id`, `version` | 同来源编号版本唯一；相同内容幂等，不同内容冲突；更正递增版本 |
| `target_id`, `track_id`, `execution_id` | 轨迹明确属于目标；更正不得改绑主体 |
| `valid_from`, `valid_to` | epoch 毫秒，左闭右开 |
| `phase` | `AIRBORNE / LANDED / UNKNOWN` |
| `takeoff`, `landing` | 可缺失；提供时必须有 `occurred_at`；`longitude`, `latitude`, `accuracy_m` 可缺失，缺少坐标或精度时位置核对不可判定；WGS-84，误差单位米 |
| `pilot_contact_id` | 稳定身份引用；姓名不能替代，须具备有效核验依据 |
| `reporting_binding_id` | 与来源一致的启用绑定；不使用经营单位或数据所属单位代替 |
| `evidence_refs` | 非空来源证据引用列表 |

响应 `data` 含 `fact_id`、`source_mode`、`duplicate`。事实及证据追加保存；接收顺序版本纳入新规则的待研判判断。当前有效声明不唯一时不可判定，不按到达顺序挑选有利证据。

四项规则：`C02-9` 起飞点、`C02-10` 降落点、`C02-11` 飞手、`C02-12` 报送单位。每项配置 `required`、`mismatch_status=ILLEGAL/UNDETERMINED`；位置项另需 `tolerance_m`、`max_accuracy_m`。严重度使用既有 C03 `severity.<原因码>` 参数。新原因分别为 `TAKEOFF_POINT_MISMATCH`、`LANDING_POINT_MISMATCH`、`PILOT_IDENTITY_MISMATCH`、`REPORTING_UNIT_MISMATCH`。

缺少或未确认的正式参数不默认判违；位置误差跨越容差边界时不可判定。距离使用 WGS-84 椭球反解；极端坐标不收敛时保持不可判定。可靠事实表明仍在飞行时，降落项不适用。新行为违规须同时通过原最终判定和证据充分性算法；独立、充分的空域违规仍保留其原判定路径。

迁移只追加候选规则版本，沿用现有影子切换接口；不自动切换 active/shadow 指针，不把 DEMO 改成 CONFIRMED。新距离及判违参数没有生产默认值，正式发布应提供业务确认依据；隔离测试参数不代表正式确认。
