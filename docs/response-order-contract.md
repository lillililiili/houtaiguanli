# 无人机处置顺序与电话后置

处置顺序是独立配置，只决定通知和反制的先后，不授予核实、反制、审批或执行权限。入口为管理后台「规则管理 → 处置顺序」。升级默认关闭，不改变原核实、反制、通知处罚规则组的开关。

## 业务约定

未命中策略时沿用原通知优先流程。命中策略且本风险已核实、依据有效时，短信和反制可并行，反制不等待短信送达或电话完成。预测和预测衍生风险仍必须人工核实、人工发起反制；独立实测风险保留已有自动规则。

默认范围为高风险、提前预警和实测两个阶段、全部空域、全天。风险等级可调整为中风险及以上，范围可指定空域，时段按北京时间且支持跨午夜。最长优先等待默认 60 秒，可设为 5～300 秒。

后台首次确认「风险已核实、当前证据有效且策略命中」时，在风险锁内建立 `response_order_window`。该窗口按 `risk_case_id` 持久保存起点、策略版本、原等待秒数及截止时间；刷新、重启、预测转实测或配置更新不会延后截止时间。只读页面请求不会建立窗口。撤销后再次发生风险使用新风险编号和新窗口。

电话顺序限制在以下任一事实成立时解除，解除后仍校验当前风险、飞手、通道、录音及原通知条件：

- 本次风险对应的设备启动命令已成功，且收到真实的完成回执。四通道设备必须是开启通道或非零开机掩码，关机回执不算启动。
- 当前范围明确没有已启用的反制设备，或启动明确失败。设备忙、离线、等待审批或结果未知不直接视为失败。
- 持久化优先期限已到。超时只解除电话的顺序等待，不代表反制成功或失败，也不阻止仍有资格的人工反制。

依据不足、已避开或风险结束时暂停新通知和动作。已接收的短信、电话保留原内容、真实回执及渠道幂等任务；结果未知不得盲目重发。电话未调用通道前重读本阶段录音和飞手并冻结发送内容；已尝试调用通道后保留原内容，不沿用同一任务偷偷换录音补呼。预测转实测后尚未发送的电话选择普通实测告警录音；仍处于预测阶段必须使用预测进入禁飞区专用录音。

每个风险、每个渠道只有一个逻辑任务。任务持久键为 `(event_id, risk_scope)`，`risk_scope` 由风险关联及历史渠道占用确定；模拟器回执通过实际 `provider_key` 查任务，不通过截取字符串猜风险身份。旧任务使用原编号和回执，不能与另一禁飞区的任务串用。

电话结果未知后，保留同次请求的标识和发送时间；同一请求迟到的真实接通、播放回执仍可补记，严格校验请求、录音和接通先后。补记不恢复已经结束的风险，不重新拨打电话，也不恢复旧反制授权。多区域共享事件的通知补发必须明确选择风险，旧接口不建立无区域归属的新任务。

升级时，已尝试发送的旧事件级任务如涉及多个区域且没有唯一、明确的历史渠道归属，不把它分配给任意区域，也不为各区域重新发送。相关区域显示旧通知归属待核查，原任务及迟到回执保留。此限制只针对已存在的歧义发送记录；没有旧发送尝试的新多区域风险继续独立通知。

自动核实和自动反制规则分别在 `automation_case_state(category, risk_case_id)` 保存状态，规则运行快照保存 `risk_case_id`。共享实测事件涉及多禁飞区时，规则的空域、电话回执、核实和授权资格分别重验；另一风险的 PASS 或已核实不能被借用。预测衍生风险的自动入口和实际发送守卫继续拒绝自动动作。旧无风险归属的规则运行及授权只有唯一明确关联时可兼容读取；多区歧义不会自动选择其中一条。

## 管理接口

沿用 `/api/v1`、Bearer 会话、snake_case 和 `{ok,data,error}`。以下接口为平台 `BackendOnly`，读取需要 `responsePlans.read` 和 ALL 数据范围，保存另需 `responsePlans.auth`。单位后台运维授权不能使用此入口。

- `GET /api/v1/response-order-policy`：读取当前配置。
- `PUT /api/v1/response-order-policy`：提交完整配置、`expected_version` 和 `Idempotency-Key`；成功追加版本、前后快照和真实操作人审计。重复幂等键或版本冲突不得盲目重提，应重新读取核对。
- `GET /api/v1/response-order-policy/history?page=1&size=20`：配置变更历史；`size` 为 1～100。

| 字段 | 值与含义 |
| --- | --- |
| `version` / `expected_version` | 当前版本 / 本次保存所依据版本 |
| `enabled` | 策略开关，默认 `false` |
| `minimum_risk` | `HIGH` 或 `MEDIUM`（中风险及以上） |
| `prediction_enabled` / `observed_enabled` | 提前预警 / 实测阶段，至少选一项 |
| `scope_mode` / `airspace_ids` | `ALL` 或 `AIRSPACES`；指定范围必须是未删除空域，编号不可重复 |
| `airspace_names` | 只读的空域名称 |
| `schedule_mode` | `ALL_DAY` 或 `DAILY` |
| `start_time` / `end_time` | `HH:mm`，指定时段起含止不含，起止不可相等 |
| `timezone` | 固定 `Asia/Shanghai` |
| `max_wait_seconds` | 5～300，默认 60 |
| `can_manage` | 当前账号是否可保存，只读能力提示 |

## 业务页面摘要

既有无人机通知概要增加 `response_order`。页面读取服务端资格，不通过 `notify_phase` 自行隐藏反制入口。

| 字段 | 含义 |
| --- | --- |
| `mode` | `NOTIFY_FIRST` 或 `COUNTER_FIRST` |
| `matched` | 当前配置是否命中 |
| `status` / `voice_status` | `NOTIFY_FIRST`、`WAITING_START`、`START_CONFIRMED`、`START_UNAVAILABLE`、`START_FAILED`、`WAIT_TIMEOUT`、`PAUSED` |
| `reason` | 当前顺序与阻断原因 |
| `policy_version` | 本次读取使用的当前策略版本 |
| `priority_started_at` / `priority_deadline_at` | 本风险持久化优先窗口，epoch 毫秒 |
| `max_wait_seconds` | 有窗口时为原窗口等待值 |
| `counter_priority` | 当前可按反制优先顺序判断；并非反制授权 |
| `phone_released` / `voice_allowed` | 仅表示电话顺序限制已解除，仍受电话资格守卫约束 |
| `phone_release_reason` | 电话解除顺序限制的原因 |
| `voice_eligible_at` | 当前持久化优先截止时间，不保证届时一定拨号 |

同概要另带 `risk_case`，提供最新 `risk_case_id`、`version`、办理事件版本及阶段，供下一次操作绑定。处置进度 `risk_case.counter` 仅在当前账号具备对应处置读取范围时返回。

数据库仅追加 `V202610230002__response_order_policy.sql`；既有规则配置、原始告警、研判、核实和回执不回填为新结论。本地与生产的通道和模拟来源门禁保持。本文件说明实现契约，不构成验收通过记录。
