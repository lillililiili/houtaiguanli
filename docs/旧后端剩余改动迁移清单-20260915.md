# 旧后端剩余改动迁移清单（2026-09-15）

旧位置为 `dongyiwurenji/server`，唯一后端为 `houtaiguanli/server`。本清单覆盖旧位置保留的全部 `src/`、`scripts/` 与 `README.md`，共76个文件。运行数据、日志与 target 构建产物不作为源码入库。核对完成后，旧目录已整体移至仓库外的本地备份并校验1889个文件；旧8080进程已停止，唯一后端继续运行在houtaiguanli的8081端口。

新增能力：无人机事件急停及设备停止联动；飞行计划报备事实（飞手、运营单位、报备起降点）；待执行计划设备预检；可选本地演示批次补充；风险列表/导出多类型筛选。保持现行 Bearer、snake_case、`/api/v1` 和现有权限；真实物理停机仍由设备回执/现场核查决定，发送请求不能当作停止成功。

## 版本与实现边界

- 新增 `V202609150002` 急停持久化、`V202609150003` PostgreSQL追加事件保护、`V202609150004` 备案字段及WGS-84范围约束，排在现有设备维护迁移 `202609150001` 后。
- 旧 `202609140001/0002` 飞行核验迁移已等价映射为 `202609140010/0011`。旧空域函数修改已有新函数迁移承接。没有修改任何已应用迁移。
- `GET /api/v1/flight-plans/{id}` 的 `filing` 只返回已有备案事实；缺失字段不伪造。起降点不被当作实际航迹端点。
- 待执行计划可读取 `/verifications/device-check`，返回 `PREFLIGHT_DEVICE_NORMAL/PREFLIGHT_DEVICE_ABNORMAL/CHECK_INCOMPLETE`；未来计划仍不能提交起飞核验或发送核验反馈。
- 风险接口支持逗号分隔 `risk_types`，最多10项、每项64字，空项拒绝；与单项 `risk_type` 同时提供时取交集。列表、总数与导出共用数据库过滤。
- 演示补充仅在local且显式开启种子配置时运行，需要明确 `app.dev-seed.flight-enrichment-prefix` 批次；`--preserve-existing-flight-demos` 保留旧计划时段，不重置历史风险。
- 保留新后端的设备逻辑删除、完整调测信息、维护任务、地图管理、运行报表和多相机模拟，不用旧文件覆盖这些能力。
