## API 契约

所有接口保持 `/api/v1`、Bearer 数据库会话、snake_case、字符串 ID，JSON 为 `{ok,data,error}`。全部入口先校验 `evidence:read`；实际轨迹另需 `target:read`。文件仍沿用 `evidence:ingest` 对未关联文件的可见性规则。组织、区域须启用，ASSIGNED 仍按组织与区域的完整元组匹配。CASE 和 AUTHORIZATION 上下文分别要求对应模块读取权限。

| 路径 | 行为 |
| --- | --- |
| `GET /evidence-ledger` | `page`、`size`、`category`、`status`、`custody`、`subject_kind`、`subject_id`、`q`；默认 1/20，最大每页 100。返回 `items/page/size/total`。 |
| `GET /evidence-ledger/stats` | 同列表筛选但不接受分页。`by_kind` 为 VIDEO/TRACK/IMAGE/COMMAND 四项；`by_status/by_custody` 只统计文件，实际轨迹和指令不伪装成文件状态或保管状态。 |
| `GET /evidence-ledger/records/{FILE\|TRACK\|COMMAND}/{id}` | 精确定位，可附完整的 `subject_kind/subject_id`。不存在、越界或不属于指定上下文返回 404。返回 `entry/links/command/attachments`；文件详情保留访问日志。 |
| `GET /evidence-ledger/materials/{EVENT\|TARGET\|CASE}/{id}` | 四类关联材料与分类覆盖情况。最多返回 1000 条，分类总数独立统计并明确 `truncated`，不假报完整。不会把元数据摘要当作文件内容完整性校验。 |
| `GET /evidence-ledger/export.csv` | 按全部筛选结果导出；兼容页面传来的分页参数，但不据此截断。超过 5000 条明确拒绝。UTF-8 BOM、公式注入防护、导出审计。 |

`entry` 明确区分 `source_kind/source_id/category`；`occurred_at` 使用取证时间，缺失时使用入库/创建时间。实际轨迹为 OBSERVED 或 NO_POINTS；设备指令保留实际状态，未收到回执返回空回执列表，不推断成功。历史文件类型不改写；四类之外的历史文件仍可精确读取。空值表示未记录或不适用。

## 本地运行

在 `server/` 中设置本项目 `DB_URL` 后，用 `spring-boot:run -Dspring-boot.run.profiles=local,qa` 启动。普通 `local` 默认保持原设置。QA 配置和规则目录准备器要求同时具有 `local`、`qa` 且没有 `production`。规则参数仍标注 DEMO，不作为业务确认参数。

QA 配置关闭自动短信、自动语音、自动反制规则、自动光电跟踪、模拟指令适配器、状态推进和移送通道。不会自动伪造恢复、设备执行或外部送达结果。无需改动已应用迁移。
