## 本机环境处理

Docker 启动遇到遗留 AF_UNIX 套接字不可访问。仅在 Docker 完全退出后处理两个临时目录，全部保留备份，没有删除或改动数据库卷、凭据文件和其他项目文件：

- `%LOCALAPPDATA%\Docker\run` 的保留目录：`run-broken-e3f953bb962143968ab4d9b678674b25`、`run-socket-backup-9ec6e581135b4d678190b07040c3b46e`。
- `%LOCALAPPDATA%\docker-secrets-engine` 当时只含 `engine.sock` 链接；保留目录：`docker-secrets-engine-socket-backup-d8e64bc051714d9591e75faff6ebed52`、`docker-secrets-engine-socket-backup-3645c66ff4e44befb86c5ab6fc9b960f`。

Docker 恢复后按自身重启策略启动的其他项目容器保持原样。一键关闭只针对本次记录的 `deploy-db-1`、`deploy-mosquitto-1`，不会退出 Docker Desktop。
