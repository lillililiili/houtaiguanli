# 报表管理升级验证记录

验证日期：2026-09-16。

## 实现范围

管理端提供综合运行、设备运维、告警与风险、飞行计划与核验、事件处置五类报表，独立选择日、自然周和自然月。统计通过各业务模块查询服务读取业务数据；旧统计和旧报表参数保持兼容。接口详见[运行统计接口契约](运行统计接口契约.md)。本次未增加或修改 Flyway 迁移。

页面、Excel 和 PDF 共享统计口径，但各次请求即时查询，不保留历史快照。设备状态为当前快照，其他状态截至生成时。PDF 每个明细分区展示最近 50 条；Excel 导出完整明细，总明细超过 50,000 条时拒绝导出。
