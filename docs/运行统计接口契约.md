# 运行统计接口契约

版本：V1.2；日期：2026-09-16。

本契约对应分析报告「运行统计」页。页面布局不变；前端不再用 `mock.js` 的 `M.stats` 作为该页数据源，改为读取本接口。当前聚合的是样本事实表，不是已落地的目标/案件领域表；正式口径仍待 Q6。

## 1. 通用约定

- 根路径：`/api/v1`。认证：`Authorization: Bearer <session_id>`。
- 字段 snake_case；日期为 `YYYY-MM-DD`，时区 `Asia/Shanghai`；金额单位为人民币元。
- 信封：成功 `{ "ok": true, "data": ... }`；失败 `{ "ok": false, "error": { "code", "message" } }`。
- 权限：`statistics.read`。`NONE` 数据范围拒绝；`ASSIGNED` 只聚合其组织/区域元组内的事实行；`ALL` 可见全部样本事实，并附带设备台账在线摘要。
- `source_mode` 为窗口内事实的 `mock/live/mixed`；全部为模拟行时 `simulated=true`。空窗口沿用应用 `source_mode`，`simulated=false`，计数为 0，不以演示值填补。
- 原运行统计消费者继续使用 `GET /stats/operations` 与 `GET /stats/operations/export.csv`，接口和口径不变。后台新报表通过 `report_category + period_type` 查询业务记录并导出 Excel/PDF；不保存历史、不定时生成。仅传旧 `report_type` 的预览/XLSX 请求保持原样本统计契约。

## 2. `GET /stats/operations`

参数：

| 参数 | 约定 |
| --- | --- |
| `from`/`to` | 可选，`YYYY-MM-DD`。缺省为当前日（上海）及其前 29 天，共 30 天 |
| 区间 | `from` 不得晚于 `to`；跨度不超过 366 天；非法日期或越界返回 `400 VALIDATION_ERROR` |

未登录 `401 UNAUTHENTICATED`；无 `statistics.read` 返回 `403 FORBIDDEN`。

`data` 主要字段：

| 字段 | 含义 |
| --- | --- |
| `from`/`to` | 实际统计闭区间 |
| `summary.total` | 空中目标次数（样本事实行数） |
| `summary.illegal` | `legal_status=非法` |
| `summary.punish` | 处罚案件数 |
| `summary.high_risk` | 风险为高风险或超高风险 |
| `summary.uav`/`abnormal` | 无人机、异常目标数 |
| `devices` | 仅 `ALL` 范围：`total`/`online`/`online_rate`（一位小数）。无设备时 `online_rate` 省略。`ASSIGNED` 不返回，避免泄露全量台账 |
| `days` | 区间内每日 `total/illegal/punish/high_risk`，无数据的日期计 0 |
| `by_risk`/`by_type`/`by_duration`/`by_track`/`alt_bands`/`by_penalty` | `{name,value}`，缺档补 0 |
| `alt_total` | 参与高度统计的目标数，等于 `summary.total`（海拔高 AMSL，样本均有值） |
| `regions` | 东营区、广饶县、河口区、垦利区、利津县、东营港经济区，按目标数降序 |
| `partners` | 主体案件数 Top 5，`case_count` 与罚款合计 `fine` |

分档与前端演示页一致：时长分钟 `0-10/10-30/30-60/60-120/120以上`，轨迹公里 `0-1/1-5/5-10/10-20/20以上`，海拔米 `0-50/50-120/120-300/300-600/600 以上`。高度未把 AGL 与 AMSL 混算。

## 2.1 `GET /stats/operations/export.csv`

与查询使用相同 `from`/`to` 和数据范围。成功返回 `text/csv;charset=UTF-8` 附件 `operations-stats.csv`，首字节为 UTF-8 BOM。列为 `分类,项目,指标,数值`，覆盖总览、分日、区域、风险、类型、时长、轨迹、高度、处罚与主体排行。`ASSIGNED` 范围不包含全量设备行。单元格按审计导出同样规则加引号，并以 `'` 转义 `=+-@` 开头，避免表格软件执行公式。成功写入审计 `stats_export_requested`。非法区间与查询相同，返回 `400 VALIDATION_ERROR`。

## 2.2 `GET /stats/reports/preview`

参数均必填：`report_type=DAILY|WEEKLY|MONTHLY`，`anchor_date=YYYY-MM-DD`。服务端按 `Asia/Shanghai` 解释日期并拒绝未来日期：日报取锚点当天；周报取锚点所在自然周的周一至周日；月报取所在自然月。当前周、当前月的结束日期截断为当天。

成功响应在原运行统计结构外增加：

| 字段 | 含义 |
| --- | --- |
| `report_type` / `anchor_date` | 经校验的报表类型与锚点日期 |
| `period_label` | 面向页面与文件标题的自然周期名称 |
| `generated_at` | 本次即时预览生成时刻，epoch 毫秒 |
| `report` | 与 `GET /stats/operations` 相同结构、权限范围和聚合口径 |

## 2.3 `GET /stats/reports/export.xlsx`

参数、周期、权限和统计口径与预览接口一致。成功返回标准 XLSX MIME，设置 `Cache-Control: no-store`，`Content-Disposition` 同时带 ASCII 回退名和 UTF-8 中文文件名。文件包含 `报表摘要`、`每日趋势`、`分类分布`、`区域与处置` 四张工作表；表头冻结并启用筛选，统计值写入数值单元格。仅 `ALL` 范围在摘要中写设备统计，其他范围不输出全量设备信息。

导出成功复用审计动作 `stats_export_requested`，详情记录 `format=XLSX`、报表类型、实际区间和 `simulated` 标志。空周期可导出全结构零值报表；`simulated=true` 的摘要显著标明“不可作为现场正式报表”。

## 3. 数据来源与限制

- 空中目标、处罚案件来自 `report_airborne_target`、`report_penalty_case`。`local`/`test` 且 `app.dev-seed.enabled=true` 时由 `LocalReportingSeeder` 幂等写入近 30 天样本；Flyway 脚本不混入演示行。
- 设备 KPI 查询 `device`/`device_state`。`local` 不再预置模拟台账，该卡可能为 0。
- 这些数字是开发样本，不能当作现场运行指标或生产验收依据。目标、告警、案件领域表就绪后应改为同源聚合，并删除样本表依赖。

## 4. 五类业务报表（后台新页面）

本节不改变上述旧接口。新增请求使用：

- `report_category=OVERVIEW|DEVICE_OPERATIONS|ALARM_RISK|FLIGHT_VERIFICATION|EVENT_DISPOSAL`
- `period_type=DAILY|WEEKLY|MONTHLY`，`anchor_date=YYYY-MM-DD`。
- 兼容以 `report_type` 代替 `period_type`；二者同时提供且不同返回 400。提供 `period_type` 但省略 category 时默认 OVERVIEW；完全未提供两个新参数则仍按旧接口处理。
- 日期规则沿用上海时区、自然周/月、当前周期截断；状态截至本次生成时。各次预览和导出即时生成，不保证不同时刻数据完全相同。

### 数据与权限

所有请求要求 `statistics.read` 和非 NONE 范围。各数据分区通过所属业务模块的查询应用服务取得，复用其查询范围约束：

| 类型 | 分区与来源 | 额外读取权限 |
| --- | --- | --- |
| OVERVIEW | targets（target.first_seen_at）、alarms（alarm.occurred_at）、risks（flight_risk.occurred_at）、plans（flight_plan.start_at）、events（uav_event.created_at） | 各分区分别要求 target:read、alarm:read、risk:read、flight:read、alarm:read |
| DEVICE_OPERATIONS | devices（ops_device/ops_device_state 当前快照）、maintenance（ops_device_maintenance_task.reported_at） | devices.read、monitoring.read |
| ALARM_RISK | alarms、risks，分别计数 | alarm:read、risk:read |
| FLIGHT_VERIFICATION | plans，关联 revision_no 最大的核验记录；无记录为 NOT_VERIFIED | flight:read |
| EVENT_DISPOSAL | events、authorizations（关联处置授权）、handoffs（关联交接及最新发送尝试） | alarm:read、disposal:read、handoff:read |

处置/交接按所属事件创建时间划入周期，其趋势与明细统计时间也使用该事件创建时间；展示当前授权、执行、发送及回执状态，不将发送成功当作办结。关联记录需与事件组织/区域一致，事件需与来源告警组织/区域一致。设备待办复用计划归属与 MQTT 共享设备双重范围；设备快照沿用设备台账的可见范围。

综合报表对无权限分区返回 `accessible=false` 并省略 total，界面显示“无权限”，不冒充 0；其他类型缺任一所需权限时整体 403，包括明细和导出。不读取旧 `report_*` 样本表，不删除旧样本或改变业务前台。

### 预览及明细

`GET /stats/reports/preview` 返回：

- 元信息：report_category、title、period_type、anchor_date、period_label、from、to、generated_at（epoch 毫秒）、source_mode、simulated、status_note。
- sections：各分区 key/title/basis/snapshot/accessible/total、days（date/value）、distributions（key/title/items{name,value}）、sources（name/value）。
- columns：各分区的明细列定义 field/label；labels：枚举展示文本，未知新枚举保留原值。
- 来源按实际记录聚合；任一 mock/replay 行令 simulated=true，混合来源为 mixed。空集合 source_mode=unknown。设备快照明确标为当前状态，不能用于推算历史在线率。

`GET /stats/reports/details` 使用相同筛选，加 `section`、`page=1`、`size=20`（1–100）。返回 items/page/size/total。总览以预览内每日/区域汇总为明细，不开放原始业务明细。排序按统计时间倒序、字符串 ID 倒序，快照按 ID 稳定排序。

### Excel 与 PDF

`GET /stats/reports/export.xlsx`、`GET /stats/reports/export.pdf` 使用相同参数和权限。均返回 attachment、UTF-8 文件名及 Cache-Control:no-store。

- XLSX：摘要、每日趋势、分类与区域、各分区完整明细。数值为数值单元格，文本为 STRING，避免执行公式。明细总计超过 50000 条或字段超过单元格长度限制时返回 400 并明确说明，不截断。
- PDF：服务端 PDFBox 生成 A4 图文报告，内嵌 Noto Sans SC 中文字体及离线矢量图表，可搜索文字；每个明细分区最多 50 条，标明展示数量、总数和完整明细入口。长行换行、跨页续表、页码齐全。
- 读取在同一只读、可重复读事务内完成；生成后独立写 `stats_export_requested` 审计，包含类型、格式、周期、区间、范围及来源。不得在只读事务内写审计。
- 不新增报表存储表、定时任务、历史快照、审批或外发功能。
