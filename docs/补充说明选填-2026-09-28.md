# 补充说明选填

用户要求核验说明及同类补充文字不必填写。本次覆盖风险核验/改判、合法性核对/重算/转告警、案件补齐/复核、短信/电话重试及运维处理说明。

- 前端移除必填标记与最小字数限制，标注“选填”。保留各字段原有 500 或 1000 字上限。
- 相应接口的 `note` 允许省略、null、空字符串和空白。风险、合法性及通知重试规范化为空字符串；案件与运维沿用各自空值存储方式。不生成代填的人工说明。
- 保留必选结论、有效版本、权限、数据范围、状态迁移、幂等、恢复核验及真实回执要求。线索内容、处置授权事由等业务主体字段仍按原契约校验。
- 新增 `V202609280007__optional_business_notes` 迁移，放宽说明非空约束；保留操作人、时间、未解决线索及待办状态的一致性约束。既有迁移和历史数据不修改。

涉及前台：`riskVerificationModal`、`legalityReviewModal`、`punishmentModals`、`AutoSmsNotice`、`AutoVoiceNotice`；管理端：`CommissionView`、`MaintenanceWorkflowPanel`。

涉及后端：`RiskVerificationService.parse/note`、`LegalityReviewService.revise/recompute/escalate/Body.note`、`PunishmentCaseService.resolveLead/review`、`UavAdvisoryService.retryAutomatic/retryAutomaticVoice/optionalRetryNote`、`DeviceMaintenanceWorkflowService.act`。
