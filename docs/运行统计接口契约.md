## 1. 通用约定

根路径 `/api/v1`，Bearer 会话，标准 `ok/data/error` 信封、snake_case 字段。日期为北京时间 `YYYY-MM-DD`；生成时间为 epoch 毫秒；罚款为人民币元，支持小数。每次查询/导出在 REPEATABLE_READ 事务中生成，导出事务允许写入既有审计；不同时间的请求可能因业务数据变化而不同。

所有接口要求 `statistics.read` 及非 NONE 范围。目标要求 `target:read`，合法性和风险分别要求 `assessment:read`、`risk:read`，案件要求 `punishment:read`。缺某源权限不泄露该分区数值：对应指标省略（JSON 全局忽略 null），`availability` 明确 UNAVAILABLE。目标与案件按同一有效组织/区域元组过滤，ALL 仍排除无业务归属目标。设备要求 `devices.read`，复用设备台账现有可见范围，ASSIGNED 不再直接省略全部设备。

`source_mode` 为已获准查询的目标/案件来源集合：`mock/replay/live/mixed`，空集合为 `unknown`。只要含 mock 或 replay 就 `simulated=true`，不将回放标成现场数据。设备状态另为当前台账快照。

## 2. `GET /stats/operations`

2026-10-09 性能调整：新增可选布尔参数 `include_observations`，默认 `true`，旧调用、CSV、周期预览和 Excel/PDF 的完整计算保持不变。业务前台已移除监测时长与里程，传 `false` 后不读取轨迹点、不校验观测来源、不计算该分区，响应省略 `observation_metrics`，不是返回零。目标、合法性、风险、案件、设备、日期与权限范围沿用同一条计算链。`source_mode/simulated` 只描述本次实际请求的分区；精简查询不纳入仅在轨迹分区出现的历史目标来源。后台 `ReportsView` 继续使用完整报表接口，无需改动。数据大屏的近 7 日趋势（`/dashboard/snapshot`）和大屏底部统计同样不需要该分区，一律走精简查询，见[大屏接口契约](backend-stage8/dashboard-api-contract.md)。

`from/to` 可选，默认北京时间今天及之前 29 天。按开始日零点至结束日次日零点半开区间读取；最多 366 天。日期格式错误、倒置、超限为 `400 VALIDATION_ERROR`；未登录为 401，缺统计权限或 NONE 范围为 403。

2026-09-28 修复：`owner_org_id` 可选，限定目标、案件及设备为同一所选单位，只能收窄当前权限范围；无效或不可见单位统一返回 `400 INVALID_ORGANIZATION`。响应回显 `owner_org_id`，未选择时省略。`GET /stats/operations/organizations` 使用相同统计读取权限，返回当前有效范围内的 `{org_id,name}` 列表。前台日期按北京时间处理；切换筛选后仅最新请求能更新图表。CSV 使用已展示结果的日期和单位参数，并记录单位范围及导出审计；周期报表接口维持原范围。

| `summary.uav/abnormal` | 当前类型为 UAV；最新合法性为 ABNORMAL |
| `summary.punish` | `punishment_case.case_id` 按 `filed_at` 统计。移送、送达、签收不等于立案 |
| `devices` | `ops_device/ops_device_state` 当前快照；排除已删除。total、online；总数为零时 online_rate 省略，非零保留一位小数 |
| `days` | 区间每日新增目标/非法/立案/高风险数量；有权限且无业务事实才为 0 |
| `regions` | 既有六区域及实际出现的其他区域，不丢弃非预置区域；总数与列表同源 |

### 第 36 项：监测时长与里程（2026-10-08）

`observation_metrics` 同时加入运行统计、旧式周期报表和五类业务报表中的 `OVERVIEW` 综合运行预览。业务前台入口为“运行统计 → 监测时长与里程”；后台入口为“报表管理 → 综合运行 → 监测时长与里程”。CSV、Excel、PDF 使用同一服务端结果；Excel 追加“监测时长与里程”表，不改变旧工作表。

| 字段 | 口径 |
| --- | --- |
| `status/reason/basis` | AVAILABLE、PARTIAL、INSUFFICIENT、NO_DATA、UNAVAILABLE 及中文解释。没有有效片段时不返回伪零时长／里程 |
| `duration_seconds` | 有效相邻实测片段时差，秒；多个目标同时观测时分别累计，不是系统开机时长 |
| `distance_meters` | 有效片段 WGS-84 经纬度间水平大圆折线距离，米；不计算高度变化，不等于真实完整航程 |
| `observed_targets/measured_targets/valid_segments` | 本期有融合轨迹的目标数、参与有效片段累计的目标数、有效片段数；均不表示飞行架次 |
| `source_modes/config_versions` | 实际读取的来源模式与参与累计的轨迹配置版本；禁止将 DEMO 参数改成已确认 |
| `exclusions` | 未计入的点或相邻片段的 `code/reason/count`；原因包括预测/桥接、资料不足、来源异常、时间断点、重复冲突、位置跳变、来源切换和轨迹重叠；不能将这些数量换算成“缺失飞行时间” |
| `days` | 北京时间逐日累计 `date/duration_seconds/distance_meters`；无可累计片段时为空 |

计算边界：

- 只读当前 UAV 目标的 FUSED 轨迹，排除已合并别名。目标首次发现可以早于统计期；原 `summary.total` 仍只计期内新增目标。RAW 不另算一次，也不跨 RAW/FUSED、目标或轨迹连接。
- 点必须为 MEAS，具有有效位置、正位置精度、独立主观测及正权重贡献观测。观测来源模式、组织/区域、无人机类别和观测时刻必须与轨迹点匹配；来源迟到/桥接导致时刻不一致时保守排除，不使用回填位置。缺少完整来源链不能假设有效。
- 连续时间上限取轨迹 `config_version` 对应 `filter.max_dt_ms` 与 `identity.short_lost_after_ms` 的较小值。相邻位置超出 `association.gate_sigma × hypot(两端精度)` 时断开；贡献观测 `anomaly_z` 超出 `quality.anomaly_zscore` 时排除。沿用已有参数用于保守统计筛选，不改变融合算法、目标关联或研判。它不是新速度阈值或判违规则，可能低估快速移动/低质量片段。
- live 轨迹配置要求 `schema_status=CONFIRMED`；模拟允许现有 DEMO。缺参、缺配置、无精度均为依据不足；不生成正式阈值、不修改激活版本。
- 按观测时刻排序；完全重复的时刻去重，同刻位置冲突中断连续性；同一观测不能反复计入。不跨预测点、桥接点或来源切换连接。同一目标多轨迹时间重叠的片段整组排除，避免任意选轨或重复累计。
- 查询窗口前后只读取已有配置允许的邻接范围，用有效片段裁剪日期边界；跨日时长按实际交集累计，里程按该有效片段的时长比例分摊。这只拆分已成立的连续片段，不跨失联区间插值，不统计未来点或最后一点后的尾时长。
- 统计源和单位范围继续沿用各入口现有规则：运行统计走 `StatisticsScope`；综合报表正式仅 live，模拟仅 mock/replay，并受原 QA 门禁限制。每条贡献观测同时验证所属元组，不能从无权限范围混入事实。缺 `target:read` 时仅返回不可用原因。
- 单次最多读取 500,000 个候选点；超限整项返回 UNAVAILABLE 并提示缩短周期，绝不拿截断数据冒充合计。无需新表、迁移、定时任务或后台菜单。

## 4. 五类业务报表（后台新页面）

本节与上述运行统计端点保持各自对象口径。新增请求使用：

- `report_category=OVERVIEW|DEVICE_OPERATIONS|ALARM_RISK|FLIGHT_VERIFICATION|EVENT_DISPOSAL`
- `period_type=DAILY|WEEKLY|MONTHLY`，`anchor_date=YYYY-MM-DD`。
- `source_mode=live|simulated`，省略为 `live`。正式口径仅纳入 `live`；模拟验收口径仅纳入 `mock/replay`，两者均排除来源未知记录。该参数选择查询口径，不更改业务记录的来源。
- 兼容以 `report_type` 代替 `period_type`；二者同时提供且不同返回 400。提供 `period_type` 但省略 category 时默认 OVERVIEW；完全未提供两个新参数则仍按旧接口处理。
- 日期规则沿用上海时区、自然周/月、当前周期截断；状态截至本次生成时。各次预览和导出即时生成，不保证不同时刻数据完全相同。

### 数据与权限

所有请求要求 `statistics.read` 和非 NONE 范围。各数据分区通过所属业务模块的查询应用服务取得，复用其查询范围约束：

| 类型 | 分区与来源 | 额外读取权限 |
| --- | --- | --- |
| OVERVIEW | targets（target.first_seen_at）、alarms（alarm.occurred_at）、risks（flight_risk.occurred_at）、plans（flight_plan.start_at）、events（uav_event.created_at） | 各分区分别要求 target:read、alarm:read、risk:read、flight:read、alarm:read |
| DEVICE_OPERATIONS | devices（ops_device/ops_device_state 当前快照）、maintenance（ops_device_maintenance_task.reported_at） | devices.read、monitoring.read |
| ALARM_RISK | alarms、risks，分别计数 | alarm:read、risk:read |
| FLIGHT_VERIFICATION | plans，关联 revision_no 最大的核验记录；无记录为 NOT_VERIFIED | flight:read |
| EVENT_DISPOSAL | events、authorizations（关联处置授权）、handoffs（关联交接及最新发送尝试） | alarm:read、disposal:read、handoff:read |

处置/交接按所属事件创建时间划入周期，其趋势与明细统计时间也使用该事件创建时间；展示当前授权、执行、发送及回执状态，不将发送成功当作办结。关联记录需与事件组织/区域一致，事件需与来源告警组织/区域一致。设备待办复用计划归属与 MQTT 共享设备双重范围；设备快照沿用设备台账的可见范围。

综合报表对无权限分区返回 `accessible=false` 并省略 total，界面显示“无权限”，不冒充 0；其他类型缺任一所需权限时整体 403，包括明细和导出。不读取旧 `report_*` 样本表，不删除旧样本或改变业务前台。

模拟口径需显式 `app.qa.reporting.enabled=true`（`APP_QA_REPORTING_ENABLED`），并满足 `local` 与 `qa` 同时启用，或独立测试 profile；存在 `prod/production` 时始终禁止。默认关闭。四个新报表端点分别执行门禁，未启用返回 403 `SIMULATED_REPORT_DISABLED`；非法口径返回 400 `VALIDATION_ERROR`。原有统计和对象权限、单位区域范围及时间边界继续生效，不因为开关开启而扩大权限。旧 `report_type` 单参数接口不支持模拟口径，明确请求时返回 400，不静默返回正式报表。`/stats/operations` 不受本开关影响。

### 预览及明细

`GET /stats/reports/preview` 返回：

- 元信息：report_category、title、period_type、anchor_date、period_label、from、to、generated_at（epoch 毫秒）、source_mode、simulated、status_note、report_scope、available_source_modes。
- sections：各分区 key/title/basis/snapshot/accessible/total、days（date/value）、distributions（key/title/items{name,value}）、sources（name/value）。
- columns：各分区的明细列定义 field/label；labels：枚举展示文本，未知新枚举保留原值。
- `report_scope` 为所选 `live/simulated`；`available_source_modes` 默认为 `["live"]`，仅允许模拟时为 `["live","simulated"]`。管理端据此显示切换入口，进入页面默认正式统计。
- `source_mode` 按所选口径内实际记录聚合：模拟数据可能为 mock、replay 或 mixed；无记录时使用所选口径名 live/simulated。模拟请求即使结果为空也保持 `simulated=true`；不能把空模拟报表当成正式报表。设备快照明确标为当前状态，不能用于推算历史在线率。

`GET /stats/reports/details` 使用相同筛选，加 `section`、`page=1`、`size=20`（1–100）。返回 items/page/size/total。总览以预览内每日/区域汇总为明细，不开放原始业务明细。排序按统计时间倒序、字符串 ID 倒序，快照按 ID 稳定排序。

### Excel 与 PDF

`GET /stats/reports/export.xlsx`、`GET /stats/reports/export.pdf` 使用相同参数和权限。均返回 attachment、UTF-8 文件名及 Cache-Control:no-store。

- XLSX：摘要、每日趋势、分类与区域、各分区完整明细。数值为数值单元格，文本为 STRING，避免执行公式。明细总计超过 50000 条或字段超过单元格长度限制时返回 400 并明确说明，不截断。
- PDF：服务端 PDFBox 生成 A4 图文报告，内嵌 Noto Sans SC 中文字体及离线矢量图表，可搜索文字；每个明细分区最多 50 条，标明展示数量、总数和完整明细入口。长行换行、跨页续表、页码齐全。
- 读取在同一只读、可重复读事务内完成；生成后独立写 `stats_export_requested` 审计，包含类型、格式、周期、区间、范围及来源。不得在只读事务内写审计。
- 模拟 Excel/PDF 的文件名和标题均含“模拟验收”，PDF 每页页眉及 Excel 各页签打印页眉保留标识；摘要说明不可作为现场正式报表。导出审计追加 `report_scope`。预览、明细、分布、趋势与导出统一过滤；页面切换后清空旧结果并丢弃迟到响应，来源不符时停止展示和导出。
- 不新增报表存储表、定时任务、历史快照、审批或外发功能。
