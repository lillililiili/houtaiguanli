# 运行统计接口契约

版本：V1.1；日期：2026-09-14。

本契约对应分析报告「运行统计」页。页面布局不变；前端不再用 `mock.js` 的 `M.stats` 作为该页数据源，改为读取本接口。当前聚合的是样本事实表，不是已落地的目标/案件领域表；正式口径仍待 Q6。

## 1. 通用约定

- 根路径：`/api/v1`。认证：`Authorization: Bearer <session_id>`。
- 字段 snake_case；日期为 `YYYY-MM-DD`，时区 `Asia/Shanghai`；金额单位为人民币元。
- 信封：成功 `{ "ok": true, "data": ... }`；失败 `{ "ok": false, "error": { "code", "message" } }`。
- 权限：`statistics.read`。`NONE` 数据范围拒绝；`ASSIGNED` 只聚合其组织/区域元组内的事实行；`ALL` 可见全部样本事实，并附带设备台账在线摘要。
- `source_mode` 为窗口内事实的 `mock/live/mixed`；全部为模拟行时 `simulated=true`。空窗口沿用应用 `source_mode`，`simulated=false`，计数为 0，不以演示值填补。
- 原运行统计消费者继续使用 `GET /stats/operations` 与 `GET /stats/operations/export.csv`，接口和口径不变。后台报表管理通过 `/stats/reports/*` 即时预览并导出 Excel；首版不保存历史、不定时生成，也不提供 PDF。

## 2. `GET /stats/operations`

参数：

| 参数 | 约定 |
| --- | --- |
| `from`/`to` | 可选，`YYYY-MM-DD`。缺省为当前日（上海）及其前 29 天，共 30 天 |
| 区间 | `from` 不得晚于 `to`；跨度不超过 366 天；非法日期或越界返回 `400 VALIDATION_ERROR` |

未登录 `401 UNAUTHENTICATED`；无 `statistics.read` 返回 `403 FORBIDDEN`。

`data` 主要字段：

| 字段 | 含义 |
| --- | --- |
| `from`/`to` | 实际统计闭区间 |
| `summary.total` | 空中目标次数（样本事实行数） |
| `summary.illegal` | `legal_status=非法` |
| `summary.punish` | 处罚案件数 |
| `summary.high_risk` | 风险为高风险或超高风险 |
| `summary.uav`/`abnormal` | 无人机、异常目标数 |
| `devices` | 仅 `ALL` 范围：`total`/`online`/`online_rate`（一位小数）。无设备时 `online_rate` 省略。`ASSIGNED` 不返回，避免泄露全量台账 |
| `days` | 区间内每日 `total/illegal/punish/high_risk`，无数据的日期计 0 |
| `by_risk`/`by_type`/`by_duration`/`by_track`/`alt_bands`/`by_penalty` | `{name,value}`，缺档补 0 |
| `alt_total` | 参与高度统计的目标数，等于 `summary.total`（海拔高 AMSL，样本均有值） |
| `regions` | 东营区、广饶县、河口区、垦利区、利津县、东营港经济区，按目标数降序 |
| `partners` | 主体案件数 Top 5，`case_count` 与罚款合计 `fine` |

分档与前端演示页一致：时长分钟 `0-10/10-30/30-60/60-120/120以上`，轨迹公里 `0-1/1-5/5-10/10-20/20以上`，海拔米 `0-50/50-120/120-300/300-600/600 以上`。高度未把 AGL 与 AMSL 混算。

## 2.1 `GET /stats/operations/export.csv`

与查询使用相同 `from`/`to` 和数据范围。成功返回 `text/csv;charset=UTF-8` 附件 `operations-stats.csv`，首字节为 UTF-8 BOM。列为 `分类,项目,指标,数值`，覆盖总览、分日、区域、风险、类型、时长、轨迹、高度、处罚与主体排行。`ASSIGNED` 范围不包含全量设备行。单元格按审计导出同样规则加引号，并以 `'` 转义 `=+-@` 开头，避免表格软件执行公式。成功写入审计 `stats_export_requested`。非法区间与查询相同，返回 `400 VALIDATION_ERROR`。

## 2.2 `GET /stats/reports/preview`

参数均必填：`report_type=DAILY|WEEKLY|MONTHLY`，`anchor_date=YYYY-MM-DD`。服务端按 `Asia/Shanghai` 解释日期并拒绝未来日期：日报取锚点当天；周报取锚点所在自然周的周一至周日；月报取所在自然月。当前周、当前月的结束日期截断为当天。

成功响应在原运行统计结构外增加：

| 字段 | 含义 |
| --- | --- |
| `report_type` / `anchor_date` | 经校验的报表类型与锚点日期 |
| `period_label` | 面向页面与文件标题的自然周期名称 |
| `generated_at` | 本次即时预览生成时刻，epoch 毫秒 |
| `report` | 与 `GET /stats/operations` 相同结构、权限范围和聚合口径 |

## 2.3 `GET /stats/reports/export.xlsx`

参数、周期、权限和统计口径与预览接口一致。成功返回标准 XLSX MIME，设置 `Cache-Control: no-store`，`Content-Disposition` 同时带 ASCII 回退名和 UTF-8 中文文件名。文件包含 `报表摘要`、`每日趋势`、`分类分布`、`区域与处置` 四张工作表；表头冻结并启用筛选，统计值写入数值单元格。仅 `ALL` 范围在摘要中写设备统计，其他范围不输出全量设备信息。

导出成功复用审计动作 `stats_export_requested`，详情记录 `format=XLSX`、报表类型、实际区间和 `simulated` 标志。空周期可导出全结构零值报表；`simulated=true` 的摘要显著标明“不可作为现场正式报表”。

## 3. 数据来源与限制

- 空中目标、处罚案件来自 `report_airborne_target`、`report_penalty_case`。`local`/`test` 且 `app.dev-seed.enabled=true` 时由 `LocalReportingSeeder` 幂等写入近 30 天样本；Flyway 脚本不混入演示行。
- 设备 KPI 查询 `device`/`device_state`。`local` 不再预置模拟台账，该卡可能为 0。
- 这些数字是开发样本，不能当作现场运行指标或生产验收依据。目标、告警、案件领域表就绪后应改为同源聚合，并删除样本表依赖。
