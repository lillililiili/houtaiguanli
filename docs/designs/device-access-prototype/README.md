# 设备统一接入页面设计

基于当前管理端设备管理页面和 2026-09-27 用户讨论制作的一版独立交互原型。

直接打开 `index.html`；或在本目录运行 `python -m http.server 8877 --bind 127.0.0.1`，访问 `http://127.0.0.1:8877/`。使用 `?view=access` 可直接打开接入弹窗。

- 沿用蓝白配色、管理端侧栏、统计卡、设备台账及右侧详情。
- 页头只保留“接入设备”；选择设备类型后，展示已支持的协议与专用字段。基本资料在切换类型时保留，协议专用字段重新填写，避免混用。
- 雷达可切换 TCP / MQTT；光电采用光电边端 MQTT；固定式四通道反制采用 TCP。其他协议设备按现有支持范围展示。
- 天气传感器纳入统一选择；目前仅保存档案，保持停用、待接入，不虚构厂家协议。
- MQTT 连接管理放在配置字段旁，支持嵌套打开并返回。连接按单位和区域复用；新增连接默认停用。
- 接入配置保存不等于连接成功、启用或设备在线。实际实现须保留后端身份、范围、来源与权限校验。
- 统一基本资料中的所属单位、区域及安装位置是本版设计建议，正式落地需核对各协议写入契约。

本原型不加载业务数据，不调用 API，不存储凭据；示例资料及新增内容仅在页面内存中保留，刷新即恢复。不是生产功能实现。
