## 页面流程

| 页面 | 操作 | 预期结果 |
| --- | --- | --- |
| 设备管理 | 接入设备 → 雷达 / 四通道反制设备 → 填资料、所属范围、设备地址、端口与协议参数 → 保存 | 调用原 TCP 接入接口；不读取 MQTT 通道，不要求配置 MQTT。保存后仍以真实报文确认状态。 |
| 设备管理 | 接入设备 → 光电 / 5G-A / TDOA | 提示沿用现有演示配置，不提供手动 MQTT 登记或连接配置入口。检查模拟器与演示环境，不重复登记已有模拟设备。 |
| 设备管理 | 选择已有 MQTT 模拟设备 → 编辑名称、型号或位置 → 保存 | 保留原协议、通道、所属范围、外部编号、提供方或边缘中心身份及来源；通道资料读取失败时禁止保存，可重试且保留草稿。 |
| 设备实时监测 | 选择同一设备 → 查看状态、趋势、事件 → 暂停 / 恢复读数 | 使用已有清单与状态接口；来源和模拟标识保持，设备状态仍按推送刷新，读取失败显示错误。 |
| 设备接入调测 | 选择设备 → 创建任务 → 建立连接 → 保存配置 → 开始调测 → 查看报告 | TCP 保持设备端点配置；已有 MQTT 使用原连接快照且地址只读。模拟调测仍要求服务端明确许可，报告保留非正式标识。 |
| 接口配置 | 查看接口类别 | 保留飞行任务输入、天气预报、电话通知录音，不再提供 MQTT 新增、编辑和启停操作。 |
