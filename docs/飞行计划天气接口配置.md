# 飞行计划与天气接口配置

2026-09-20。本次先实现配置草稿和设备档案，真实对接依赖来源系统、服务商及设备协议资料。

## 已实现 API

统一 /api/v1、Bearer、snake_case、标准 ApiResponse；ID 字符串、时间 epoch 毫秒。

- GET /external-interface-configs/{kind}：interfaces.read；kind=FLIGHT_PLAN 或 WEATHER_FORECAST。
- PUT /external-interface-configs/{kind}：interfaces.op；version（乐观锁）和 name 必填。source_code/direction(PUSH/PULL)/allowed_cidrs 仅用于计划；area_name/interval_minutes/validity_minutes 仅用于天气。endpoint 只接受不含用户名密码、query、fragment 的 HTTPS 地址，推送方式不接受客户端填写接收地址。credential_ref 只支持 env:变量名，禁止填密钥本身。其余字段可空，不预设厂商、更新频率或有效期。
- 返回 version、updated_at、status（NOT_CONFIGURED/AWAITING_ADAPTER）、enabled=false、message 和已保存字段。保存有审计；失败不报成功；没有实现接收/采集/连接测试或启用入口，草稿不会自动生效。
- GET /flight-plans/{id}/weather-forecast：先复用 FlightReadService 校验 flight:read 和同一计划数据范围；返回 plan_id/status/message。当前没有 forecast 数值，不能当成已实现预报服务。
- POST /weather-sensors：devices.op；device_no/name/owner_org_id/district_id 必填，vendor/model/address 可空。保存到 ops_device + ops_integration_source + device_business_scope，真实来源但未接入、无上报、默认停用。内部 WEATHER_PENDING 是未接入标记，不代表厂家协议。
- GET/PUT /weather-sensors/{id}：devices.read/op 与精确单位区域范围；PUT 要求 version，设备编号/所属范围不能在该入口改动。通用设备写入不能绕过登记入口，启用始终阻断到协议实际实现。
- 原 /devices 台账查询支持 type_code=weather_sensor；未知状态筛选包括无状态上报的设备。观测时间和值均不生成占位事实。

## 后续：用户授权天气模拟接口（2026-09-20）

本节替代上文“天气仅能保存草稿、没有 forecast”的阶段状态；计划输入与传感器边界不变。

天气配置新增 source_mode=live/mock，默认 live。mock 必须填写 area_name，仅 local/test 且无 prod/production profile 开放；生产环境保存拒绝，读取不返回模拟。迁移 V202609200003 仅追加列与约束，既有配置默认 live，不自动启用。

每次管理员保存 mock 生成一个发布时间为 updated_at、有效期 24 小时的稳定批次（以配置 version + updated_at 标识）。后台状态 SIMULATED/STALE，enabled 仅当前有效模拟为 true；前台接口 READY/STALE 返回 forecast，包含 area_name、provider_name、published_at、source_mode=mock 和六个四小时时段 periods。时段字段 from/to 为 epoch 毫秒；temperature_c 摄氏度、wind_speed_ms/gust_ms 米每秒、wind_direction_deg 度、precipitation_probability_pct/humidity_pct 百分比。输入 interval_minutes/validity_minutes 对模拟不执行，后台模拟模式不显示这些正式接口资料字段。

读取不写库、不刷新发布时间；切回 live 没有正式适配器时明确待接入，不回退模拟。本次区域预报不是计划航线/时段的匹配结果，不生成气象风险、通知或设备观测。配置保存沿用权限、版本锁及审计，预报沿用计划对象范围。后台选模拟接口并保存；到期后再次保存生成新批次，切回真实接入并保存即停用模拟。
