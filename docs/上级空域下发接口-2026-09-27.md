# 上级空域下发接口

2026-09-27 用户确认：空域由上级接口下发，业务前台只读；设备模拟器增加上级空域下发模拟。本文件替代阶段 9 中默认由业务前台手工创建、修改和加载空域数据包的入口约定。旧数据保留原始来源，不追溯改成上级下发。

## 接收入口与鉴权

- 正式：`POST /api/v1/integrations/airspaces/messages`。
- 本地模拟：`POST /api/v1/local-interface-simulator/airspaces`，仅 `(local | test) & !prod & !production` 注册；服务器固定来源 `local-airspace-upstream`、模式 `mock`。
- 模拟资料：`GET /api/v1/local-interface-simulator/airspaces/context`，返回可见的 `scopes` 与最近 100 个空域的最新回执 `items`。归属候选最多 1000 个组合；不自动创建单位、区域或测试空域。
- 沿用 Bearer 数据库会话、snake_case、`{ok,data,error}`。写入要求接口操作权限（`interfaces` 为 OP 或 AUTH）及 `airspace:read`、`airspace:manage`；读取要求接口读取及空域读取权限。归属按启用单位、启用区域和当前用户精确范围校验。
- 正式入口额外要求 `app.airspace.upstream.source-id`、`app.airspace.upstream.user-id`；来源须已在 `integration_source` 注册为启用的 `live`、协议 `AIRSPACE_PUSH_V1`。接收账号必须与部署绑定账号一致，不从请求体采信来源或操作者。不配置返回 `503 UPSTREAM_NOT_CONFIGURED`，来源不符返回 `503 UPSTREAM_SOURCE_UNAVAILABLE`，不回落到模拟。
- 本次定义的是平台接收契约；具体上级供应商协议、注册适配、账号和网络尚未提供，不代表已完成真实上级联调。真实适配应将供应商数据转换到此契约，并按部署授权注册来源。

## 新建与更新

```json
{
  "message_id": "upper-airspace-001-v1",
  "revision": 1,
  "action": "UPSERT",
  "airspace_no": "UPPER-001",
  "name": "上级下发空域",
  "kind_code": "PROHIBITED",
  "boundary": {"type":"MultiPolygon","coordinates":[[[[118,37],[118.01,37],[118.01,37.01],[118,37.01],[118,37]]]]},
  "min_altitude_m": null,
  "max_altitude_m": null,
  "altitude_datum": null,
  "valid_from": 1790467200000,
  "valid_to": null,
  "change_reason": "上级首次下发",
  "owner_org_id": "已启用且授权的单位ID",
  "district_id": "已启用且授权的区域ID"
}
```

`message_id` 为 1~64 个字母、数字、横线或下划线；`revision` 为正整数。边界使用 WGS84，经度在前、纬度在后。种类沿用 PROHIBITED、RESTRICTED、ALTITUDE_LIMIT、PERMITTED、TEMPORARY_CONTROL。高度下限、上限、基准必须三者全空或全有，基准仅 AGL/AMSL，不能默认为可互换。时间使用 epoch 毫秒，模拟器按北京时间展示。

同一来源、同一空域编号再次 UPSERT 会追加版本，接替时关闭旧版有效期，保留旧版几何及历史研判引用。名称、归属不允许在版本更新中切换。`valid_from` 必须晚于上一条已接受下发的生效/撤销时刻；拒绝乱序及回溯覆盖，不从客户端接收本地 `expected_version`。编号已被其他来源或旧本地空域占用时拒绝接管。

## 撤销

```json
{
  "message_id": "upper-airspace-001-withdraw",
  "revision": 2,
  "action": "WITHDRAW",
  "airspace_no": "UPPER-001",
  "effective_at": 1790470800000,
  "change_reason": "上级撤销"
}
```

撤销关闭最新版本有效期，不删除空域、几何或历史。撤销时间必须晚于最新版本生效时间，并早于已设置的失效时间；存在未来版本时不能用更早时刻撤销覆盖其历史。未来撤销只表示已接收该变更，在指定时刻前旧版本仍有效。已撤销后可用更高 revision 和更晚 valid_from 重新下发完整内容。

## 幂等与回执

- 按来源和消息编号查重；相同 JSON 对象重发返回原始回执，字段顺序无关。同编号改内容返回 `409 SOURCE_MESSAGE_CONFLICT`。
- 同空域 revision 必须递增，否则 `409 UPSTREAM_REVISION_CONFLICT`；来源行锁、数据库唯一约束和事务共同保护并发。
- 每次重放也重新校验当前权限和数据范围。内容、版本、来源、真实账号审计和回执同一事务提交；失败不返回接受回执。
- 回执字段：`message_id, airspace_id, airspace_no, airspace_version_id, revision, action, state=ACCEPTED, source_mode, received_at`。
- `ACCEPTED` 表示平台已接收并保存，是否当前生效仍以版本有效期为准；不自动通知、不下发设备控制指令。

## 历史兼容与运行

真实或来源未知的目标、计划、告警只使用 `live` 空域；模拟/回放业务可使用 `live`、`mock`、`replay` 空域。空间命中、版本歧义、计划冲突及飞离观察使用相同规则，避免模拟空域影响真实研判。列表仍展示授权范围内资料，并明确标识模拟/回放。

人工创建、追加版本、GeoJSON 导入写入口默认不注册。仅历史维护/兼容测试可显式开启 `app.airspace.legacy-write-enabled=true`，即使开启也不允许覆盖上级下发空域。版本列表、详情及差异读取继续保留。

新增迁移 `V202609270001__upstream_airspace_delivery.sql` 仅登记模拟来源元数据并建立下发回执表，不预置演示空域。模拟器入口为 `http://127.0.0.1:8766/?input=airspaces`；正式供应商接入前可先通过该入口验证接收、重发、更新、撤销。模拟数据明确标识 mock，不直接向数据库插入业务夹具。
