# 本地模拟观测补充契约

2026-10-10，七流程问题修复。所有入口保留 `/api/v1`、Bearer 会话、snake_case、`{ok,data,error}`、组织和区县范围校验；模拟来源不能冒充真实设备。验收服务保持开发种子关闭。

## 场景双源通道

目标 `transport=normalized` 使用已登记的规范化模拟观测源，携带 SN、AMSL、AGL、识别置信度和遥控器位置。可选 `secondaryTransport=normalized` 使选定辅助设备也走规范化入口，每台设备仅报一次该目标；缺省 `auto` 保留辅助设备能使用自身 MQTT 协议时通过 MQTT 上报的行为。主目标为 MQTT 时不能指定规范化辅助通道。设备状态仍按自身协议上报，不扩展设备协议字段。

## 独立设备身份（2026-10-16）

`POST /api/v1/local-interface-simulator/observation-devices` 新增可选字符串 `origin_ops_device_id`（最多 36 字符），取设备受控登记结果的台账 `device_id`，即模拟器 manifest 的 `platform_id`，不是规范化观测源生成的融合 `device_id`。先登记本场景协议设备，再注册规范化观测源。新关联要求调用者具备接口操作权限及提交单位、区域权限；原设备与原协议来源均启用、原设备未退役且明确标记模拟，并有完整匹配的 MQTT、光电边端或 TCP 雷达登记关系，原设备和融合设备均须属于提交的单位、区域。找不到明确关系时拒绝关联，不按名称或设备类型猜测。返回结构仍为 `source_id/device_id/message_id`。

该字段参与请求幂等摘要。同一 `message_id` 更改、增加或删除原设备关联返回 409；新关联使用新消息编号。原有不带字段的请求及其摘要保持兼容，旧登记和旧观测不回填。无关联的规范化观测仍可进入原融合链路，但不计入独立设备数量。

核实规则 `sourceCount` 使用最近 60 秒（包含边界、不含未来）的本目标有效观测，按明确关联的台账设备去重。同一设备的 MQTT、光电、TCP 或规范化辅助通道观测只算一台；来源、设备、单位、区域或传输模式不匹配的观测不计入，身份未知不猜测。规则证据记录台账设备与实际观测编号，设备后续停用、退役或关联失效时不再用于当前计数。其他事实的现用全局有效期不变。

## 区域天气预报

`POST /local-interface-simulator/weather` 新增可选字符串 `district_id`（最多 36 字符）。提供时按稳定区县 ID 匹配授权范围内且时段重叠的计划；显示名称不能覆盖区县关系。旧输入缺失该字段时仅按规范化后的区域全名精确匹配，不能子串匹配。计划 ID、来源和时段约束继续生效。风险原因保存天气事实，不冻结“当前待核验”等会失效的状态文案。

## 气象观测回读

`GET /local-interface-simulator/weather-devices/{device_id}/observations` 读取已登记的模拟气象设备，需接口读取权限及该设备组织/区县范围。响应 data：`source_id`、`device_id`、`source_mode=replay`、`simulated=true`、整数 `total` 和可选 `latest`。最新记录按 `observed_at`、接收时间、消息编号依次倒序；不是最后到达者覆盖更新观测。无观测为 total=0 且不返回 latest；设备不存在 404、未登录 401、权限不足 403。latest 保持原观测字段与 epoch 毫秒时间，不生成零值代替未知。回读不写入业务状态。

## 高度与时间

停报的空终止帧保留最后一次已取得的 AMSL/AGL，但观测时间不前移，不据此声称观测有效。空间风险按航线高度基准使用同次观测中已上报的 AMSL 或 AGL；高度带规则仍使用 AGL，不推算基准转换。新风险入库时，仅同基准且航线上下限齐全才保存 WITHIN/OUTSIDE（上下界含等号），其余 UNKNOWN；高度关系不代表风险解除，历史风险不回写。任务风险摘要与风险详情同源显示数值及基准。业务链与模拟器展示时间统一 Asia/Shanghai。

## 七流程场景重复运行

生成的无人机编号包含关联航线几何、高度带、宽度和时间字段的稳定指纹。修改这些事实后使用新的模拟机号，避免与历史同机号、同时段的旧计划歧义；只改显示名称不改变身份。同一场景重复运行仍复用相同配套计划。历史记录保留，不以删除旧计划解决匹配问题。需要验证执行完成与停止的流程使用四通道 TCP 模拟接收端，并继续遵守急停与授权门禁。

模拟飞手的短信/电话撤离以本批次已确认模拟回执时刻作为轨迹反应起点；只在回执距当前不超过 5 秒且不早于本批次时补偿轮询延迟。下一条位置仍以当前实际发送时刻上报，不补写过去观测，不重启已触发轨迹。过期或未来回执不补偿；停报模式不能冒充飞离。按2026-10-13确认，业务端短信送达和电话播放完成后的固定等待均为0秒；2026-10-16确认流程2按有效撤离观测和电话/反制动作的实际先后顺序验收，不能保证短信送达后不拨电话。
