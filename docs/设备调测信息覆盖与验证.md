## 页面与采集链路

调测页面按设备显示「实时工参与协议」「设备档案与配置」「感知样本」「厂家资料与型号依据」。共有 245 项字段定义，按实际协议选用，包含不同协议复用的字段；不是声称每台设备具备 245 项遥测。列表会分页读取全部启用设备，信息每 10 秒刷新，也可手动刷新。读取失败清除旧展示并显示错误，切换设备时阻止旧请求覆盖新设备。

来源分为平台登记、设备上报、厂家标称。缺失值不填 0；真实的 0、false、空目标数组保留。协议数据超过 30 秒、无接收时间或上报时间异常时显示过期。格式/枚举错误显示异常。定向设备覆盖角度为条件必填；频率起止值与非空频段数组可替代。光电空闲 taskId=null 表示当前不适用。协议必填项完整不表示现场验收通过。

## 接口

`GET /api/v1/commission-tasks/device-information/{deviceId}`，Bearer 数据库会话、`commissioning.read`、有效业务数据范围。ALL 可读取；ASSIGNED 必须匹配同一启用组织/区域元组；NONE 或无映射拒绝。设备已删除或不在范围返回 404 `DEVICE_NOT_FOUND`。连接和协议配置额外要求 `devices.op`，否则逐字段 REDACTED；从白名单组装响应，口令和 credential_ref 不返回。

保持 `{ok,data,error}`、snake_case、字符串 ID。data 字段为 `device_id/device_no/name/model/protocol_code/source_mode/simulated/generated_at/task_supported/sections/sample_sections/notes`。

section 包含 `code/title/source/observed_at/received_at/fields`；field 包含 `key/label/value/unit/required/status/note`。时间为 epoch 毫秒；未提供的节级时间遵循现有 null 忽略设置；field.value 的缺失使用显式 JSON null。字段 key 保留原协议大小写和层级路径。支持 RECEIVED、STALE、NOT_REPORTED、INVALID、CONFIGURED、NOT_CONFIGURED、REDACTED、NOT_APPLICABLE。配置与历史记录使用登记状态，不纳入实时必填获取计数。

MQTT A/C 仅展示主动上报信息，`task_supported=false`，页面隐藏不支持的创建调测任务入口。既有 TCP 调测状态机保持原有行为。
