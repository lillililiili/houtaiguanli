# 统一无人机风险与提前预警

2026-10-22 用户确认实施。此文记录业务和接口契约；测试结果单独记录，不代表已完成验收。

## 风险与证据

同一目标、同一禁飞区、同一次持续风险使用稳定字符串 `risk_case_id`。预测转实际入区沿用该编号。原预测告警、实际告警、研判、输入快照、通知及设备回执不删除、不复制为新事实。关联仅使用既有同目标、单位、区域、来源及实际入区链接；无明确关系的历史保持独立。不同禁飞区和撤销后新风险独立核实。

风险阶段为 `PREDICTED / ENTERED / OBSERVED / CLEARED / UNKNOWN / ENDED`，分别表示预计入区、实测入区、其他实测风险、已避开、依据不足和已结束。阶段与核实状态、短信/反制/电话进度分别返回。未知、过期、停报均不视作已避开；尚未确认停止的设备处置保留待处理。

新增核实账本保存当时风险与事件版本、预测引用、当前复核依据、真实操作人和时间。系统自动核实明确保存 `AUTO` 和对应规则运行；不得伪造人工操作人。2026-10-25 用户确认：预测阶段只能人工核实；同一风险进入 `ENTERED` 且本禁飞区当前实测入区依据有效后，尚未核实的当前办理事件可以按后台已启用自动核实规则办理，全部条件满足才自动核实。无启用规则、条件不足或依据未知时不自动，人工入口仍按原资格开放。此前已人工/自动核实或已判误报的同周期风险不再核实。预测及其衍生风险仍只能人工发起反制。

核实处置资格不将预测改写为违法研判，也不构成处罚依据。预测衍生的实测自动核实只写当前区域风险账本、实际规则运行和实测依据，不回写原事件的处罚核实事实。唯一且完全独立的实测风险沿用原实测依据检查，在同事务保存真实人工核实的原事件状态、版本和历史，使原处罚材料读取保持兼容；独立实测原自动核实历史也兼容。多区域和有预测来源的历史成员不能借共享原事件的核实结论确认另一风险或形成处罚依据。

## 实测反制完成后的移送（2026-10-27）

经历过提前预警不影响后续满足条件的自动移送。反制结束且真实停止确认后，按后台已启用的通知处罚规则判断；规则全部满足、接收方和原渠道资格有效时自动通知处罚部门。该动作是移送材料，不是系统自动作出处罚决定。`manual_counter_only` 只限制反制发起方式，不能用来隐藏或禁止移送进度。

预测衍生风险须另外读取本风险明确关联的 OBSERVED 事件、充分 ILLEGAL 研判和可追溯的 MEAS 位置，核对同一目标、禁飞区、单位及来源，以及观测当时有效的空域边界和高度。该观测及研判必须早于本次真实反制完成时间；其他区域、其他风险、完成之后才出现的实测，不能给本次移送补依据。模拟来源继续受 local,qa 门禁并保留模拟标识。历史实测证明已经发生的入区事实，不因目标后来飞离而被删除；通知处罚规则中的时效仍按原配置独立判定。

风险核实仅表示该周期的处置资格，不能替代独立实测违法依据，也不将原预测或实测事件的旧核实状态回填为处罚事实。新移送材料同时保存原始材料和独立实测依据引用、风险编号、空域版本、授权及真实完成回执。纯预测、没有充分实测证明或未确认停机的处置不能自动移送。

同风险周期维护唯一处罚交接关系，预测转实测、重复扫描、刷新、重启或多个关联事件不能新增重复交接。不同禁飞区独立办理，旧记录没有明确区域归属时保持原历史，不按时间接近或名称猜测。未发送任务重验最新规则；已受理、结果未知、送达及签收回执不改写，不盲目重发，旧人工通知决定保持原约定。

页面保留移送进度和具体阻断原因；已完成反制可继续显示待移送、已移送或移送受阻。只在后端明确返回等待规则且尚未发送时说明规则满足后自动发送，不能把超时、未知结果或旧人工决定显示成等待自动重发。

## 接口

统一响应、Bearer 会话、snake_case 和字符串 ID 不变。

| 接口 | 契约 |
| --- | --- |
| `GET /api/v1/alarms?view=risk_case` | 在服务端分页、计数前归并风险。非无人机告警保留原口径；不传 view 时保持原始告警兼容。 |
| `GET /api/v1/alarms/overview` | 固定统一风险口径、沿用告警读取权限及范围。返回北京时间当日 `today`（`total/pending_verification/confirmed/false_positive`）、同口径 `excluded_mock`、跨日 `pending_disposal` 及 `occurred_from/occurred_to`。一次查询生成页面统计；读取失败保持未知。 |
| 原告警导出加 `view=risk_case` | 同列表筛选及权限，增加风险编号、风险阶段，进度按风险聚合。 |
| `GET /api/v1/uav-risk-cases/{id}` | 返回 `risk_case`、代表告警 `alarm`、处置资格投影 `event`、通知及反制摘要 `advisory`。 |
| `GET /api/v1/uav-risk-cases/{id}?purpose=verification` | 仅返回同权限范围的 `risk_case`、`alarm`、`event` 和当前核实依据，省略通知摘要与核实历史；完成展示数据读取后重读当前风险并检查依据，阶段切换时重新绑定办理事件。该只读上下文不授予反制权限。 |
| `POST /api/v1/uav-risk-cases/{id}/verifications` | `Idempotency-Key`、`conclusion`、`expected_version`、`expected_case_version`；可带 `note`、`risk_case_id`，预测核实带 `prediction_id`。仅接受 CONFIRMED/FALSE_POSITIVE；版本或当前依据变化拒绝。 |
| 原申请/直接反制/审批/执行/通知重试 | 增加 `risk_case_id` 和 `expected_case_version`；服务端重验事件关联、当前依据、权限及授权。多区必须明确风险。 |
| 原授权列表加 `risk_case_id` | 查询同风险所有关联事件的授权，跨预测/实测阶段保留原授权；有明确唯一关联的旧授权可读取。 |

`risk_stage` 筛选支持逗号分隔的上述阶段。统一详情包含风险版本、当前办理事件及版本、核实状态、依据引用、人工反制标记、允许动作、阻断原因和并行进度。缺少读取权限的数据继续隐藏；风险接口不授予目标、设备或反制读取权限。

持续风险已核实后不可重复核实。预测核实延续为关联实测阶段的处置资格，但每次实际操作仍重新检查本区域当前有效实测入区关系。旧授权主体、设备和期限保持，停止或失效后不恢复。旧事件接口同样受风险守卫约束；不能靠省略风险字段跨区域办理。

实际入区后，风险阶段和处置资格改用现行 C03 `fresh_seconds` 实测时效，不再要求 K03 方向稳定或未来线仍在 3 秒有效期内。当前融合点必须是可追溯的有效 MEAS，身份、单位、来源、位置质量及当前禁飞区版本均一致；最新位置和高度仍明确在本区内，且具有本风险关联的有效、充分实测违规研判。新观测已出区、位置未知、外推点、断流/终止、来源质量异常、空域版本变化或最新研判不再有效时，不得继续借旧入区依据。预测阶段及未来线继续按原严格时效处理；这项接管不恢复已停止授权，也不解除预测衍生风险的人工反制与处罚隔离限制。

## 渠道与并发

短信、电话各有持久化风险渠道占用和逻辑任务。新任务按风险与原事件绑定；初始化 WAITING 就固定任务归属，转阶段不能另建同渠道任务。重试沿用原任务/提供商幂等键；已受理、未知和迟到回执保留实际结果，未知不盲目重发。旧已尝试任务在升级时按明确且唯一的风险链接保留占用及原键。历史已发送任务涉及多区域且归属不明时保留原记录并暂停重新通知，不猜测归属；无旧发送尝试的新多区风险继续分别办理。旧事件级撤离快照也不能同时解除多个区域。

人工或自动核实通过时，在核实事务内登记同风险短信逻辑任务，事务提交后立即唤醒独立后台发送检查，不等待历史事件轮询、反制启动或电话。发送仍重验当前风险、飞手及通道；已发送、已受理或结果未知的原任务不重发。核实回滚不调度，停机或队列繁忙导致唤醒未执行时，由原持久任务轮询恢复；核实事务不执行通知资格投影或外部通道调用。

锁顺序为预测周期、风险、事件、授权/设备。撤销、失效、核实、授权、排队启动和发送前检查共享风险边界。未发送内容按发送时阶段选用文案/录音；已尝试受理的内容冻结。预测撤销或未知使未发送动作退出资格，运行设备使用现有停止/回执/重试机制，停止未确认继续显示。停止、取消和真实回执不因风险版本推进而被新动作守卫阻断。

预测消费与融合、实测研判争用时，先非等待取得目标、预测任务和全部开放周期的锁；未全部取得即结束该目标本轮事务并保留待办，不写失败结论、不生成快照、不延长原有效期。锁齐后才取得本轮计算时刻和稳定实测输入，避免拿锁前的新观测被更早的调度时刻误判。真实计算失败和真实依据失效仍执行原暂停及停止保护，业务办理的周期/风险/事件锁顺序保持。

## 页面与模拟

融合感知以“无人机风险”统一显示有效预测与实测，保留航线风险。卡片按风险编号稳定更新；选中目标、展开和视频不因阶段变化重建。无效预测退出融合页；告警处置仍保留依据不足及停止未确认。实际轨迹实线，预测虚线、空心点和10/20/30秒标签。光电仍以当前实测位置、本目标任务回执和媒体就绪为播放条件。

目标、预测、告警及设备分段独立刷新，每段最多一个在途读取；慢告警不阻塞新实测及预测。离开页面后不发布旧请求结果或迟到错误，同一连续刷新故障不重复弹窗。新有效无人机风险按稳定风险编号提醒并展开风险列表，预测转实测只更新原记录。阶段描述当前依据，核实状态描述当前办理结果，两者独立显示；预测阶段显示待人工核实，实测阶段显示待核实及规则/人工办理说明，不能把人工反制标记当成禁止自动核实。后台融合、预测使用独立有界调度池，通知及规则扫描保留原默认调度池；不放宽观测时效，不把处理延迟重新标记为有效实测。

后台“处置顺序”独立于自动反制规则，升级默认关闭。命中时短信并行、反制优先；电话在真实启动回执且风险持续时开放，明确无法启动/失败或优先期限到期进入电话资格判断。默认60秒，可设5～300秒；从首次核实通过、依据有效且命中时持久化起算。刷新、转换和重启不重置，等待到期不绕过飞手、通道、录音和当前风险资格。

电话等待期间展示已配置的最长优先等待时间。实际发送前最后一次资格判断通过时冻结当次处置顺序依据；通话回执展示真实结果及该次触发原因，不能根据后来修改的策略或当前风险状态推断历史拨打原因。旧已发送任务没有该快照时保持缺失，不回填；结果未知、迟到回执和重试不改写已受理内容的依据。

融合感知的实时风险清单与已选中风险的办理上下文独立。当前清单短暂缺项或读取失败时，已选中的同区域风险不能退成“已观测”，须明确更新中或依据不足并暂停新动作；过期未来线和无效地图清单仍退出。跨预测和实测办理事件时按风险身份及当前事件关联校验，不能比较两个不同事件的版本号来拒绝新事件结果。核实弹窗使用轻量的当前核实上下文，提供重新读取依据入口；不延长预测有效期，也不绕过服务端提交时的风险、版本和有效依据检查。反制点击立即显示读取进度并防重复，读取超时或上下文变化时明确反馈，不静默丢弃操作。

核实点击立即显示可取消的依据读取窗口，当前预测展示与可核实依据取自同次读取，不扫描冻结历史来替代当前依据。处置摘要同时匹配风险版本、阶段与核实状态；经过关系校验的新版本可推进选中上下文。同一风险对象的正常刷新不取消反制准备，真正切换风险、离页或停止办理时才取消，提交资格仍重新检查。

统一风险核实弹窗单次在途自动重读当前轻量上下文，原位更新阶段、依据及可核实资格，保留人工选择和说明。提交前重新读取当前同风险绑定；提交过程中才发现阶段变化时保留输入并提示重新核对，不自动提交。已核实的账本结果只读展示，结果未知时只读核对并保留原请求及幂等键，不因阶段改变创建另一笔核实请求。核实写事务在返回展示详情之前提交，避免完整通知及处置详情读取长期占用周期锁。

处置资格概览的直接读取使用只读可重复读快照，使同次响应中的风险阶段、当前依据及按钮资格一致；下一次请求读取新的依据，实际提交与发送继续执行当前写守卫。卡片短信、反制、电话行固定保留；反制摘要使用与按钮相同的当前允许字段及阻断原因，不能把入口可见当成可执行。未知处置顺序显示更新或暂停，不推断为切回通知优先。目标退出地图后，已选中风险仍使用同一紧凑卡并标注最后观测，暂停新动作，不恢复地图中过期目标。反制表单以同一风险身份保持，明确提交前解析当前办理事件并重验资格；未知结果保留原主体、版本、设备及幂等键，不将重试改成新的阶段动作。

流程1/2/3日常默认使用连续的区外接近→提前预警→后续处置航迹；流程1继续入区时检查后台自动核实规则，流程2按真实短信回执转向避开，流程3缺飞手时如实不能通知。首次发现已在区内移入补充场景，保留原独立实测自动规则验证。流程4保留误报与预测误报，流程5保留原中低风险人工审批及通知优先。预警时已核实的持续风险进入后不再次核实，告警、短信和电话按原风险周期防重。原流程9退出日常选择列表，导入文件和历史仍可读取。模拟仅发送观测和通道真实模拟回执，不注入业务成功结论，也不自动开启后台规则。
