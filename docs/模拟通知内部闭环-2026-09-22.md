# 模拟通知内部闭环与验收

日期：2026-09-22。范围仅现有五类通知内部模拟链路，不新增正式适配器，不修改既有接收关系、自动发送范围或开发库停用配置。

## 页面与操作

告警及融合感知的飞手短信遇到通道异常、空结果或发送租约过期时显示“发送结果未知”，不提供补发。明确失败仍须后端判断当前资格后才可重试，沿用稳定 provider_key。停用自动短信后仅核对旧 SENDING 任务，过期转 UNKNOWN；不创建新任务、不调用短信接口。电话接通/播放按原独立记录展示，短信成功不替代电话。

计划反馈与通知上级将 SUBMITTED 显示为“送达待确认”；通道已调用但结果不明时明确显示“发送结果未知，请先核对原发送记录”。未配置仍显示未接通，不能把未知发送伪装为从未发送。处罚通知保留送达与签收两套状态。任何通知结果不改变风险解除、反制授权或案件办结。

后台“通知配置”的诊断除当前接收对象/通道外，核对自动短信/电话任务开关；电话同时调用既有真实文件 WAV 校验（名称、文稿、文件格式、有效音频帧等）。诊断只读，不启用服务。

## 接口与持久化

沿用事件 advisory、auto-sms/retry、通知目录、handoff、计划 feedback 现有接口和权限。新增短信任务状态 UNKNOWN，与明确 FAILED 分开。当前配置/接收资格及历史任务/接收对象快照分别保留，后续数据过期、停用配置、联系人或录音变动不覆盖旧送达或播放事实。

共享模拟投递返回未知时为 `delivery_status=SUBMITTED`、`receipt_status=PENDING`、`blocked_reason=DELIVERY_OUTCOME_UNKNOWN`。异常、空响应、无法识别的状态及已调用后只返回 PENDING_DELIVERY 都不能认定未发送。请求幂等、同事件任务唯一性、计划每次核验反馈唯一性保持原规则；UNKNOWN 不提供新强制重发或人工伪造回执入口。

追加 Java Flyway 迁移 `V202609220001__automatic_sms_unknown_result`：仅将短信状态 CHECK 增加 UNKNOWN，保留其他状态与“送达必须有记录”约束；不改已应用迁移、不回填旧记录。部署新版前须正常应用该迁移。

## 五类验证关系

| 链路 | 触发、关联与独立验证 |
| --- | --- |
| 飞手短信 | 关联新鲜无人机观测、同事件明确非法且证据充分的研判及计划飞手。后端调度，不依赖页面；未配置/live 阻断，并发仅一次、明确失败资格重试、未知禁止重发、旧成功保留 |
| 电话录音 | 相同业务资格、独立通道与任务；有效临时 WAV 夹具只含测试静音，不含正式业务录音。接通/播放时间分开；逆序、缺失或未知结果不冒充播放成功。短信 UNKNOWN 与电话成功可同时存在 |
| 通知上级 | 固定“上级”接收关系；模拟目录及冻结快照沿用。通道结果未知保留，原交接约束阻止重复发送 |
| 计划反馈 | 当前核验、实际报送单位绑定及冻结联系人；模拟送达及未知均落反馈记录，同次核验不重复反馈，不推断已经起飞或风险解除 |
| 处罚部门通知 | 冻结交接材料及收件人；发送与审计/记录分步事务，明确失败重试、未知阻断、只读刷新；送达与签收独立；PostgreSQL 并发仅一次调用 |

## 隔离与验收边界

正式测试在 H2 及两套本次新建 PostgreSQL/PostGIS 验收库运行：`advisory_verify_connectivity_20260922`（随机 schema，测试结束删除该 schema）和既有处罚测试要求的 `handoff_notice_verify_connectivity_20260922`。不使用开发业务库，不批量启用历史停用通道。场景通过测试夹具配套来源、目标、计划、研判、告警、联系人、任务、投递/回执关联；模拟时效由测试固定/受控，停止条件为测试方法/进程退出。未发送真实短信、拨打电话或向真实部门发送信息。

PostgreSQL 用例包括 `AutoSmsPostgresTest`（迁移升级与历史逐项比对）、`AutoVoicePostgresTest`、`DirectoryConnectivityPostgresTest`、`FlightNotificationPostgresTest`、`HandoffNotificationPostgresTest`。前台保留 `tools/notificationConnectivity.test.cjs`；更多精确结果见本批交付记录。

重启恢复通过持久化 in-flight 任务、超时租约和提交失败后恢复验证，不冒充操作系统强杀再重启实测。旧通知上级/计划反馈仍在原事务内调用本地模拟适配器，本次不宣称其已具备正式远程通道的 outbox/回调能力。真实视频、正式短信/录音/部门通道仍未接入。
